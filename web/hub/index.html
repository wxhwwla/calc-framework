ℹ️ 关于

Game Calc Hub 是 Calc Framework 项目的社区插件市场。

  • 底层引擎：calc-framework — 通用 DAG 数值仿真框架（GPL）
  • 适配器：各游戏的数值计算包（独立资源，自由分享）
  • 插件：GUI 主题、OCR 规则、公式模板

本市场静态托管于 GitHub Pages，无需后端服务器。
