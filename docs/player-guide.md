**推荐方式**。不需要下载任何东西，浏览器打开就能用。

1. 打开浏览器，访问 **[wxhwwla.pythonanywhere.com](https://wxhwwla.pythonanywhere.com)**

## 2. 快速开始（桌面版）

如果你更喜欢用桌面软件，或者想使用 OCR 截图导入功能：

1. 打开 [Releases 页面](https://github.com/wxhwwla/calc-framework/releases)
2. 下载最新的 `终末地伤害计算器_Setup.exe`
3. 双击安装（Windows 可能会弹出 SmartScreen 警告，点击「更多信息」→「仍要运行」）
4. 安装完成后桌面会出现快捷方式，双击打开

> 💡 **提示**：桌面版支持 OCR 功能——截一张游戏里的角色面板图，粘贴进去就能自动识别属性。

## 3. 终末地伤害计算入门

这是最核心的功能：选角色 → 调参数 → 看伤害。

### 3.1 基础计算（"计算"页签）

<!-- TODO: 插入主界面截图 -->

1. **选择角色**：点击左侧角色下拉框，选择你想计算的干员
2. **选择武器**：选择该角色装备的武器
3. **调整等级/潜能/信赖**：用滑块调整到目标数值
4. **查看属性**：右侧面板会显示计算后的完整属性值（攻击力、防御力、暴击率等）
5. **查看伤害**：「总伤害」面板展示各技能段和各乘区的伤害数值

### 3.2 各区域说明

| 区域 | 作用 |
|------|------|
| 角色/武器/装备选择 | 选择计算对象，切换角色时伤害自动更新 |
| 技能等级面板 | 调整各技能的等级（影响倍率） |
| 敌方参数 | 设置目标的防御力、抗性、失衡值 |
| 属性列 | 展示完整的计算后属性（含所有加成） |
| 总伤害面板 | 分段展示各技能的伤害计算过程 |
| 暴击/异常微调 | 手动覆盖暴击率、异常状态等参数 |

## 4. 高级功能

### 4.1 搜索最优配装（"搜索"页签）

想知道你的角色带哪套装备伤害最高？用这个功能：

1. 切换到「搜索」页签
2. 确认角色和武器已选好
3. 设置搜索范围（可选装备数量、搜索深度）
4. 点击「开始搜索」
5. 等待结果（视装备数量而定，通常几秒到几分钟）
6. 结果按伤害从高到低排列，绿色高亮的是最优配装

> 💡 **提示**：搜索结果可以导出为 JSON，下次直接导入，不用重新搜索。

### 4.2 OCR 截图导入（桌面版专属）

游戏里截一张角色面板 → 自动填入计算器：

1. 在游戏里打开角色面板
2. 截图（Win+Shift+S 或者 PrintScreen）
3. 在桌面版计算器点击「OCR 导入」按钮
4. 粘贴截图
5. 识别完成后，角色会自动选中并填入属性

### 4.3 批量对比

想对比多个角色或配装的伤害？

1. 配置好第一个方案
2. 点击「保存为预设」
3. 更改角色或装备，保存第二个预设
4. 点击「批量对比」，选择要对比的预设
5. 查看对比图表

### 4.4 伤害图表

计算完成后，点击「伤害仪表盘」查看可视化的伤害分布图（柱状图/饼图）。

## 5. 明日方舟计算器

如果你玩的是原版明日方舟（非终末地）：

1. 在左侧导航栏点击「明日方舟」
2. 选择干员（按职业/星级/分支筛选）
3. 系统会自动解析技能描述并计算伤害
4. 支持物理/法术/真实三种伤害类型

> 💡 明日方舟数据来自 BWIKI 爬取，包含 420+ 干员的完整数据。

## 6. 常见问题

### 网页打不开 / 加载很久？

- PythonAnywhere 免费服务器在空闲一段时间后会被休眠，首次访问需要等 10–20 秒唤醒
- 刷新页面通常能解决
- 如果持续无法访问，检查网络或尝试用手机热点

### 数据不对 / 跟游戏里不一样？

- 游戏版本更新后数据可能有变化，计算器数据更新通常滞后 1–3 天
- 检查等级/潜能/信赖是否与游戏内一致
- 如果确认是数据问题，请在 [GitHub Issues](https://github.com/wxhwwla/calc-framework/issues) 反馈

### 找不到某个角色？

- 确认你的计算器版本是最新的
- 新角色通常在游戏更新后 1–3 天内录入
- 你也可以通过「贡献数据」页面自行添加

### 为什么搜索结果跟预期不一样？

- 搜索算法是按总伤害排序的，如果你更关心特定技能的伤害，可以调整搜索设置
- 固定配装模式下，只会搜索你选定的装备组合，确保装备槽位正确

### 我想贡献数据 / 报告问题？

- **反馈 Bug**：在 [GitHub Issues](https://github.com/wxhwwla/calc-framework/issues) 新建 Issue
- **贡献数据**：打开 Web 版的「贡献数据」页面（`/contribute`），填写表单提交
- **参与开发**：阅读 [贡献指南](https://github.com/wxhwwla/calc-framework/blob/main/CONTRIBUTING.md)
