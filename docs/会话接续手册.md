## 1. 项目是什么

《终末地》伤害相关 **桌面 GUI 计算器**（CustomTkinter）。当前能力：

- 选角色/武器、等级、潜能、信赖与**左侧技能等级** → 角色/武器属性列 + **右侧乘区**（15 乘区链）
- **单段伤害**、**乘区快照**、单/多技能**快速预览**（装备采样，非全量）
- **单技能全量遍历**：预计组合数/耗时、并行线程（默认逻辑核−1）、可取消、弹窗 TopN；**MVP 导出/续跑**（`search_output/`）
- 数据：`characters.json` / `weapons.json` / `equipments.json`；BWIKI 工具链可同步

**尚无**：多技能全量遍历产品化、完整总伤结算 UI、GUI 敌方参数面板等。

## 2. 用户要求与产品约定（接续时勿忘）

### 2.1 开发与协作

| 项 | 约定 |
|----|------|
| **TDD** | 用户附 `/tdd` 时：垂直切片，一测一实现；测**行为**不测实现细节 |

| **覆盖本地** | 禁止擅自跑 `github_download_module.py`（需输入 `覆盖本地`） |
| **手册** | 较大功能完成后提醒人类更新本文 §3–§4 与文首日期 |

### 2.2 全量搜索（单技能）

| 项 | 约定 |
|----|------|
| **装备词条** | 搜索必须计入 `属性词条`（战技/连携/终结伤害%、四维、攻击力% 等），不能只读 `效果`/`三件套效果` |
| **剪枝「无益」** | `prune_non_beneficial`：无效果文案且**无** `属性词条` 的装备剔除 |
| **优先级排序** | 按角色**主能力/副能力**（`主能力`/`副能力` 字段）与目标**技能类型**对装备排序（先遍历更优配装，**不减少组合总数**）：主+副 > 仅主 > 仅副 > 无；有该技能伤害加成 > 无 |
| **遍历装备件数** | GUI **1–4**：`1`=仅护甲变动，`2`=+护手，`3`=+配件A，`4`=四格全套；未遍历格固定为各部目录**排序后第一件** |
| **预计 vs 进度** | 「预计组合数」与进度条总数须同一套规则（`optimizer_config_for_character` + `varying_slot_count`）；改件数/逻辑后**勿用旧 `search_runs.db` 续跑对比** |
| **武器/装备范围** | 与 GUI「武器候选范围」「装备范围」一致；等级、倍率取左侧选择与确认 |

### 2.3 多技能快速预览

| 项 | 约定 |
|----|------|
| **权重已废弃** | GUI 为 **次数**（战技×N、连携×N、终结×N）；总伤 = Σ(单次伤害 × 次数) |
| **技能倍率** | 来自左侧战技/连携/终结**等级**；仅等级>0 且倍率有效的技能进入场景 |
| **默认** | 未开「手动次数」时：当前选中技能 ×1，其余 ×0 |

### 2.4 GUI 体验

| 项 | 约定 |
|----|------|
| **字体** | 与系统一致（`utils/gui_fonts.py`，`TkDefaultFont`） |
| **启动** | 最大化（`utils/gui_window.py`，Windows `zoomed`） |
| **布局** | 6 列 grid，权重见下表；中间「计算与搜索」列 min **360px**，长文案 `bind_wrapped_label` 换行 |
| **武器特殊能力** | 界面只显示**效果词条**（如 `寒冷伤害+`），不展示触发条件；`extract_effect_display_name()`，计算仍用完整名 |

**主界面列（`gui.py` → `APP_COLUMN_WEIGHTS = (0,0,1,1,1,5)`）**：

| 列 | 内容 | 说明 |
|----|------|------|
| 0–1 | 角色/武器选择 | min ~260px |
| 2 | 计算与搜索 | 可伸缩，min 360px |
| 3–4 | 角色/武器属性 | 可伸缩，min ~168px |
| 5 | 乘区数据 | 主伸缩列 |
