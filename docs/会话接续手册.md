## 1. 项目是什么

《终末地》伤害相关 **桌面 GUI 计算器**（CustomTkinter）。当前能力：

- 选角色/武器、等级、潜能、信赖与**左侧技能等级** → 角色/武器属性列 + **右侧乘区**（15 乘区链）
- **单段伤害**、**乘区快照**、单/多技能**快速预览**（装备采样，非全量）
- **全量遍历**：单技能或（开启「使用手动次数」时）**多技能加权总伤** TopN 弹窗；预计组合数/耗时、并行线程（默认逻辑核−1）、可取消；**MVP 导出/续跑**（`search_output/`）
- **固定配装**：底栏可勾选 0–4 件具体装备，未勾选部位在候选范围内遍历
- **工具与分享**（底栏）：配装 JSON 导入/导出、操作日志、计算历史（最近 10 次）、伤害仪表盘（**matplotlib 为运行时依赖**，见 §4.12）、插件敌人下拉（`plugins/enemies/`）、**多方案对比**（`preset_batch_compare` + `parallel_evaluate`）
- 数据：`characters.json` / `weapons.json` / `equipments.json`；BWIKI 工具链可同步

**尚无**：完整总伤结算 UI、完整敌方参数面板（抗性等）、按优先级裁减装备组合数等（见 §5）。

## 2. 用户要求与产品约定（接续时勿忘）

### 2.1 开发与协作

| 项 | 约定 |
|----|------|
| **TDD** | 用户附 `/tdd` 时：垂直切片，一测一实现；测**行为**不测实现细节 |
| **注释** | 中文 |
| **范围** | 最小 diff，不扩未请求功能 |
| **GitHub** | **默认由人类**在 `[根]` 跑 `python github_upload_module.py`；Agent 勿裸 `git push`，除非当次明确要求上传 |
| **覆盖本地** | 禁止擅自跑 `github_download_module.py`（需输入 `覆盖本地`） |
| **手册** | 较大功能完成后提醒人类更新本文 §3–§4 与文首日期 |

### 2.2 全量搜索（配装枚举）

| 项 | 约定 |
|----|------|
| **装备词条** | 搜索必须计入 `属性词条`（战技/连携/终结伤害%、四维、攻击力% 等），不能只读 `效果`/`三件套效果` |
| **剪枝「无益」** | `prune_non_beneficial`：无效果文案且**无** `属性词条` 的装备剔除 |
| **优先级排序** | 按角色**主能力/副能力**与目标**技能类型**对装备排序（**不减少组合总数**） |
| **固定配装** | 底栏「固定配装（0–4 件）」：勾选部位并选具体装备则固定；**未勾选**部位在「装备范围」过滤后的 catalog 内**全部遍历**（`FixedLoadoutSelection` + `gui_design/fixed_loadout_controls.py`） |
| **评分：单技能** | 未开「使用手动次数」：按左侧**当前选中技能**的单段伤害 TopN |
| **评分：多技能** | 已开「使用手动次数」且次数不全为 0：TopN 按 **Σ(单段伤害 × 次数)**（`evaluate_multi_skill_task`）；弹窗标题「多技能加权全量遍历」；`run_signature` 含次数 token |
| **预计 vs 进度** | 与 `optimizer_config_for_character` + `fixed_loadout` 一致；改固定件/次数/范围后**勿用旧 `search_runs.db` 续跑对比** |
| **武器/装备范围** | 与 GUI「武器候选范围」「装备范围」一致；技能倍率来自左侧技能等级 |

### 2.3 多技能快速预览

| 项 | 约定 |
|----|------|
| **权重已废弃** | GUI 为 **次数**（战技×N、连携×N、终结×N）；总伤 = Σ(单次伤害 × 次数) |
| **技能倍率** | 来自左侧战技/连携/终结**等级**；仅等级>0 且倍率有效的技能进入场景 |
| **默认** | 未开「手动次数」时：快速预览为当前选中技能 ×1，其余 ×0；**全量**仍按 §2.2 单技能评分 |
| **全量** | 开「手动次数」后，**快速预览与全量遍历**均按加权总伤（见 §2.2） |

### 2.4 GUI 体验

| 项 | 约定 |
|----|------|
| **字体** | 与系统一致（`utils/gui_fonts.py`，`TkDefaultFont`） |
| **启动** | 最大化（`utils/gui_window.py`，Windows `zoomed`） |
| **布局** | **5 列 + 底栏**（`gui_layout.py`）；底栏横跨左四列：操作 / 全量搜索 / 多技能次数；长文案 `bind_wrapped_label` |
| **确认刷新** | `confirm_refresh.py`：输入签名未变不重绘三列；最小化/失焦不触发整页清空；「确认选择」可 `force` 刷新 |
| **武器特殊能力** | 界面只显示**效果词条**（如 `寒冷伤害+`），不展示触发条件；`extract_effect_display_name()`，计算仍用完整名 |

**主界面（`APP_COLUMN_WEIGHTS = (0,0,1,1,5)` + `CONTROL_DOCK_ROW`）**：

| 区域 | 内容 | 说明 |
|------|------|------|
| 列 0–1 | 角色/武器选择 | min ~260px |
| 列 2–3 | 角色/武器属性 | 可伸缩 |
| 列 4 | 乘区数据 | 主伸缩列 |
| 底栏左 | 确认、计算模式、数据来源、**工具与分享** | 预设/日志/历史/仪表盘/插件敌人 |
| 底栏中 | 全量遍历、固定配装、预估、MVP | |
| 底栏右 | 多技能次数、手动开关 | |

| 项 | 说明 |
|----|------|
