## 1. 项目是什么

《终末地》伤害相关 **桌面 GUI 计算器**（PySide6） + **终末地数据设计器**（data editor / formula inverter）。

### 计算器能力

- 选角色/武器、等级、潜能、信赖与**左侧技能等级** → 角色/武器属性列 + **右侧乘区**（15 乘区链，框架 ComputeSheet DAG 驱动，9 节 layout 全部 22 个输出）
- **单段伤害**、**乘区快照**、单/多技能**快速预览**（装备采样，非全量）
- **全量遍历**：单技能或（开启「使用手动次数」时）**多技能段级加权总伤** TopN 弹窗；预计组合数/耗时、并行线程（默认逻辑核−1）、可取消；**MVP 导出/续跑**（`search_output/`）
- **双页签 GUI**：**计算页**（五列主视图 + 快速确认）与 **高级页**（操作 / 全量搜索 / 多技能）；顶部页签 +「前往高级页 / 返回计算页」
- **固定配装**：高级页可勾选 0–4 件具体装备，未勾选部位在候选范围内遍历
- **工具与分享**（高级页）：配装 JSON 导入/导出、操作日志、计算历史、伤害仪表盘（matplotlib）、**敌方参数面板**（防御/抗性/失衡易伤完整微调）、多方案对比
- **SearchEngine 框架化**：`EndfieldSearchEngine` 适配器包装搜索流水线，`SearchRunner.run_with_engine()` 消费
- 数据：`characters.json` / `weapons.json` / `equipments.json`；BWIKI 工具链可同步

### 设计器能力

- **公式反推**：输入属性 90 级 / 技能 9–12 级数据反推成长公式
- **数据编辑**：图形化新增/编辑/删除角色、武器、装备，保存后自动刷新缓存
- **数据浏览**：查看角色/武器/装备 JSON 列表

### 三目标打包

`build.py --target calculator`（计算器，含 matplotlib 仪表盘）和 `build.py --target designer`（数据设计器，排除 gui_design/ 减小体积）和 `build.py --target layout-editor`（布局编辑器，含角色/武器数据预览）。

**尚无**：按优先级裁减装备组合数等（见 §5）。

### 2.2 全量搜索（配装枚举）

| 项 | 约定 |
|----|------|
| **装备词条** | 搜索必须计入 `属性词条`（战技/连携/终结伤害%、四维、攻击力% 等），不能只读 `效果`/`三件套效果` |
| **剪枝「无益」** | `prune_non_beneficial`：无效果文案且**无** `属性词条` 的装备剔除 |
| **优先级排序** | 按角色**主能力/副能力**与目标**技能类型**对装备排序（**不减少组合总数**） |
| **固定配装** | 高级页「固定配装（0–4 件）」：勾选部位并选具体装备则固定；**未勾选**部位在「装备范围」过滤后的 catalog 内**全部遍历**（`FixedLoadoutSelection` + `gui_design/fixed_loadout_controls.py`） |
| **评分：单技能** | 未开「使用手动次数」：按左侧**当前选中技能**的单段伤害 TopN |
| **评分：多技能** | 已开「使用手动次数」且段级次数不全为 0：TopN 按 **Σ(各段单段伤害 × 次数)**（键如 `连携技:1`）；`evaluate_multi_skill_task`；弹窗/预览/仪表盘可展示段级分项 |
| **预计 vs 进度** | 与 `optimizer_config_for_character` + `fixed_loadout` 一致；改固定件/次数/范围后**勿用旧 `search_runs.db` 续跑对比** |
| **武器/装备范围** | 与 GUI「武器候选范围」「装备范围」一致；技能倍率来自左侧技能等级 |

### 2.3 多技能快速预览与段级次数

| 项 | 约定 |
|----|------|
| **段级次数** | GUI 按角色 JSON **各段倍率**动态生成行（如「连携技 第1段」「第2段」）；次数键 **`战技:1`**、**`连携技:2`** 等 |
| **总伤** | **Σ(段单次伤害 × 次数)**；支持「2×段1 + 1×段2」；**默认全 0**，只填需要计入的段 |
| **预设兼容** | 旧 `{"连携技": 2}` 导入时归一为 `{"连携技:1": 2}`（`skill_segments.normalize_manual_segment_counts`） |
| **技能倍率** | 来自左侧战技/连携/终结**等级** + 段索引；仅等级>0 且该段倍率有效时进入场景 |
| **默认** | 未开「手动次数」：快速预览为当前选中技能 ×1；**全量**仍按 §2.2 单技能评分 |
| **全量** | 开「手动次数」且至少一段次数>0：**快速预览、全量遍历、MVP** 均按段级加权总伤 |
| **开关刷新** | 切换「使用手动次数」走轻量刷新（`_suppress_full_confirm_refresh`），避免整窗 destroy 闪屏 |

### 2.4 GUI 体验

| 项 | 约定 |
|----|------|
| **字体** | 与系统一致（`utils/gui_fonts.py`，`TkDefaultFont`） |
| **启动** | 最大化（`utils/gui_window.py`，Windows `zoomed`）；启动页策略见 `ui_preferences.py`（默认总是计算页） |
| **双页签** | 顶层 `CTkTabview`：**计算页** + **高级页**；切页不重建控件、不丢输入；关闭时保存 `ui_preferences.json` |
| **计算页** | 五列主视图（`APP_COLUMN_WEIGHTS = (0,0,1,1,0)`）；角色/武器选择用**普通容器**（非 Scrollable）；乘区下方 **确认选择 + 前往高级页** |
| **高级页** | 原底栏三列迁入：**操作 / 全量搜索 / 多技能次数**（宽屏搜索:多技能 **2:3**；窄屏第二行 **2:3**）；窄屏（`<1480px`）自动两行重排 |
| **折叠降噪** | 角色侧 **信赖**在主区 + **技能等级**折叠；武器侧 **武器技能**折叠（内分普通/特殊技能）；两侧默认展开、关应用记住状态 |
| **按钮尺寸** | `PRIMARY_ACTION_BUTTON_HEIGHT=40` / `SECONDARY_ACTION_BUTTON_HEIGHT=32` |
| **确认刷新** | `confirm_refresh.py`：输入签名未变不重绘三列；最小化/失焦不触发整页清空；「确认选择」可 `force` 刷新 |
| **待确认配装** | `loadout_pending.py`：等级/信赖/技能/武器词条/高级页计算选项等改动**不自动**刷新三列；换角色/武器名仍即时刷新；两枚「确认选择」同步显示「待更新」；启动与预设导入仍 `force` 确认 |
| **武器特殊能力** | 界面只显示**效果词条**（如 `寒冷伤害+`），不展示触发条件；`extract_effect_display_name()`，计算仍用完整名 |
| **武器词条展示** | `display_lines.weapon_bonus_display_uses_percent`：**附加攻击力+**、四维+、主/副能力+ 为**固定整数**；**攻击力+**、*伤害+、*率+、充能效率 带 `%`（与 `final_attack_zone` 一致） |

**计算页（`MAIN_CONTENT_ROW=0`，五列）**：

| 区域 | 内容 | 说明 |
|------|------|------|
| 列 0–1 | 角色/武器选择 | min ~260px；角色 **信赖**主区 + **技能等级**；武器 **武器技能**（普通/特殊） |
| 列 2–3 | 角色/武器属性 | **可伸缩** |
| 列 4 | 乘区数据 | **固定宽约 340px**；底部快速操作行 |

**高级页（`CONTROL_DOCK_ROW=1` 语义复用为高级页 body 行）**：

| 区域 | 内容 | 说明 |
|------|------|------|
| 左 | 返回、确认、计算模式、**工具与分享** | 「更多设置」折叠：导入导出/分析/维护/启动页策略 |
| 中 | 全量遍历、固定配装、预估、MVP | hint 框固定行高 |
| 右 | **多技能次数**（段级 + 手动开关） | 段列表外层定高 + 内层 Scrollable（**勿**对 Scrollable 调 `grid_propagate(False)`） |

### 4.25 能力值加成：平值/百分比两阶段 + normal_skills 直读（2026-05-26，进行中）

**背景**：武器数据中技能存储在 `normal_skills` / `special_skills` 列表，旧计算逻辑只从武器顶层 dict key 直接读（如 `weapon["主能力+"]`），导致所有武器加成全被遗漏。同时 `主能力+`/`副能力+`/`全能力+` 是**百分比加成**，而非平值。

**新的正确计算模型**：

```
主能力_平值 = 角色基础 + 主能力值+ + {main_attr}+ + 装备 + 信赖
主能力_最终 = 主能力_平值 × (1 + 主能力+%/100 + 全能力+%/100)

副能力_平值 = 角色基础 + 副能力值+ + {sub_attr}+ + 装备
副能力_最终 = 副能力_平值 × (1 + 副能力+%/100 + 全能力+%/100)

能力值加成 = 主能力_最终 × 0.005 + 副能力_最终 × 0.002
```

### 4.35 `**kwargs` + `dict[str, int|str]` 拆包修复（2026-05-28，已完成）

**背景**：用户报告 `calculate_attribute_zones_with_details` 调用处 `reportArgumentType` 错误，`int|str` 同时不匹配 `int` 和 `str` 形参。

**根因分析**：

1. [`zone_snapshot.py:L87`](../games/endfield/calculation/multiplicative_zones/zone_snapshot.py#L87) — `WeaponBonusSelection.calculation_kwargs()` 返回 `dict[str, int | str]`
2. [`adapter.py:L104`](../games/endfield/calculation/multiplicative_zones/dag/adapter.py#L104) — `kwargs = selection.bonuses.calculation_kwargs()` → 变量推断为 `dict[str, int | str]`
3. `**kwargs` 拆包 → 每个 keyword 值是 `int | str` → 对 `int` 形参和 `str` 形参同时报错

**修复**：在两个调用点标注变量为 `dict[str, Any]`（拆包语义上确实没有 per-key 粒度）：

| 文件 | 行 | 修复 |
|------|-----|------|
| `calculation/.../dag/adapter.py` | 104 | `kwargs: dict[str, Any] = ...` |
| `calculation/.../zone_snapshot.py` | 165 | `kwargs: dict[str, Any] = ...` |

**效果**：消除 148 个级联类型错误（包端 538→390）。

**原则**：当 `**kwargs` 拆包时，变量应标注为 `dict[str, Any]` 以抹平联合值类型。这不是偷懒——是类型系统在 `**` 语法的真实能力边界。

**文档更新**：[`docs/代码规范-ruff修复模式.md`](代码规范-ruff修复模式.md) §7.2 新增 `**kwargs` 拆包 + 联合值类型条目。

**勿重复做**：在返回 `dict[str, T1 | T2]` 的函数返回类型上加 `Any`（正确做法是在调用点宽化）；将 `**kwargs` 替换为具名关键字传递（破坏兼容性）。

| 乘区 | 公式 | 输入参数 |
|------|------|----------|
| 基础伤害区 | 最终攻击力 × 技能倍率 | 最终攻击力(1000), 技能倍率(1.0) |

| 伤害加成区 | 1 + 伤害类型 + 技能类型 + 失衡 + 其他 | 4 种加成(0.0) |
| 伤害减免区 | 1 - 减免总值 | 减免值(0.0) |
| 增幅区 | 1 + 增幅总值 | 增幅(0.0) |
| 虚弱区 | 1 - 虚弱总值 | 虚弱(0.0) |
| 庇护区 | 1 - 庇护值 | 庇护(0.0) |
| 脆弱区 | 1 + 脆弱总值 | 脆弱(0.0) |
| 易伤区 | 1 + 易伤总值 | 易伤(0.0) |

| 抗性区 | 1 - (抗性-无视)/100 | 抗性(20), 无视(0) |
| 非主控减伤区 | 1 - 非主控减伤 | 减伤(0.0) |
| 连击增伤区 | 1 + 连击增伤 | 连击增伤(0.0) |
| 特殊乘区 | 特殊乘区系数 | 系数(1.0) |

**链图结构**：`const(1.0) × [复合:基础伤害区] × [复合:暴击区] × ... × [复合:特殊乘区] = 最终伤害`

- 链图嵌入在 `15乘区链.json`，位于 ZIP 包中
