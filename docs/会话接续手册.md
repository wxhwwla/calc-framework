## 1. 项目是什么

《终末地》伤害相关 **桌面 GUI 计算器**（CustomTkinter）。当前能力：

- 选角色/武器、等级、潜能与信赖 → 展示属性曲线与**右侧乘区**（防御、四维、能力值加成、攻击力链）
- **尚无**完整「总伤结算」产品功能（乘区展示为主）
- 数据来自预烘焙 `characters.json` / `weapons.json`；BWIKI 工具链可同步 Wiki → JSON + seed 脚本

| 谁做 | 做什么 |

| **你** | 在 `[根]` 运行 `python github_upload_module.py`（可加 `--minor`、`--no-bump`）；需要时先本地 `pytest`、打包自测 |

## 7. Agent 硬性规则

- **上传 / 推送**：**默认由人类执行** `github_upload_module.py`；Agent 仅在用户**当次明确要求**时代跑；禁止裸 `git commit` + `git push`
- **就绪后**：说明改了什么、测试是否通过，并提醒用户自行在 `[根]` 运行上传脚本
- **覆盖本地**：禁止擅自跑 `github_download_module.py`（需用户输入 `覆盖本地`）
- **注释**：用户规则要求**中文注释**
- **TDD**：用户附 `/tdd` 时按垂直切片：一测一实现，测行为不测实现细节
- **范围**：最小 diff，不扩未请求功能
- **许可/数据**：改 JSON 或第三方数据时对照 `docs/数据来源与许可.md`
