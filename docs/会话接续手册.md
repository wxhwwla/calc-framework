## 1. 项目是什么

《终末地》伤害相关 **桌面 GUI 计算器**（CustomTkinter）。当前能力：

- 选角色/武器、等级、潜能与信赖 → 展示属性曲线与**右侧乘区**（防御、四维、能力值加成、攻击力链）
- **单段伤害计算**（15 乘区）、**乘区快照**、单/多技能**快速预览**（采样）
- **单技能全量遍历**（弹窗 TopN、预计组合数/耗时、并行线程说明、可取消）+ **MVP 导出/续跑**（`search_output/`）
- **尚无**完整「总伤结算」产品化 UI（多技能全量、敌方参数面板等待接）
- 数据来自预烘焙 `characters.json` / `weapons.json` / `equipments.json`；BWIKI 工具链可同步 Wiki → JSON

## 7. Agent 硬性规则

- **上传 / 推送**：**默认由人类执行** `github_upload_module.py`；Agent 仅在用户**当次明确要求**时代跑；禁止裸 `git commit` + `git push`

- **注释**：用户规则要求**中文注释**

- **范围**：最小 diff，不扩未请求功能
