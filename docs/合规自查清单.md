# 合规自查清单

发布版本、接受捐赠或洽谈商业许可前，建议逐项核对。**勾选不代表已获法律意见。**

## A. 软件（LICENSE）

- [ ] 仓库根目录包含 [`LICENSE`](../LICENSE)，且与分发物一致  
- [ ] 若提供在线服务（SaaS），已评估 AGPL-3.0 第 13 条源码提供义务，或已取得商业许可  
- [ ] 商业合作已准备书面协议（参考 [`商业许可要点.md`](商业许可要点.md)），未仅用邮件口头约定  
- [ ] 再分发（含修改版）保留版权声明与「数据来源与许可」入口  
- [ ] 未将 B 站充电/打赏与「出售软件副本」捆绑  
- [ ] 捐赠入口已明确声明「不构成购买软件的对价」；GUI 捐赠文案未暗示商业授权  
- [ ] 未把工具输出（.calcpack、layout.json）错误地声称受 AGPL 约束（它们是用户的独立作品，见 `数据来源与许可.md` §5.4）

## B. 数据（DATA_LICENSE）

- [ ] 分发包内附带 [`DATA_LICENSE`](../DATA_LICENSE)（若包含 JSON 数据）  
- [ ] 发布包为 **文件夹**（`dist/终末地伤害计算器/` 或 `dist/数据设计器/`）：含 exe、JSON、`DATA_LICENSE`；勿只发 exe  
- [ ] 商用产品**未**内置本仓库 `characters.json` / `weapons.json`  
- [ ] 商用方数据来源已在合同/文档中写明「自行取得」  
- [ ] 非商业分发已保留 BWIKI / 游戏权利方必要署名（见 GUI 与 [`NOTICES`](../NOTICES.md)）  
- [ ] `tools/bwiki_scout/output/` 未误打进发布包  
- [ ] 配置包设计器导出的 .calcpack **不含**本仓库 JSON（导出时仅包含用户录入数据）

## C. 第三方与平台

- [ ] 已阅读并遵守终末地 **游戏用户协议** / 官方 fan 指引（如有更新请重读）  
- [ ] BWIKI 使用：署名、非超负荷爬取（请求间隔 ≥1s）、遵守 robots.txt、CC BY-SA 4.0 及站点版权声明  
- [ ] 未使用未授权的游戏美术、音乐、logo 作为软件图标或宣传素材（除非另有授权）  
- [ ] [`NOTICES.md`](../NOTICES.md) 与依赖许可证列表已更新（含 PySide6 LGPL、EasyOCR Apache 2.0、ultralytics AGPL-3.0）  
- [ ] 新增依赖已按 [`docs/代码结构规范.md`](代码结构规范.md) §3.11 完成许可检查（禁止引入 GPL-3.0 / SSPL）

## D. 宣传与商标

- [ ] 未暗示「鹰角官方」「BWIKI 官方合作」等未经授权表述  
- [ ] 项目描述已标明「非官方爱好者工具 / 数据仅供参考」  
- [ ] 嵌入 .calcpack 的捐赠 widget 不暗示与鹰角网络或 BWIKI 有合作

## E. 争议预防（文档）

- [ ] 用户可通过 GUI 打开 [`docs/数据来源与许可.md`](数据来源与许可.md)  
- [ ] README 已链接 LICENSE、DATA_LICENSE、合规文档  
- [ ] 用户反馈入口明确（如 GitHub Issues 模板）  
- [ ] 重要变更（许可、数据范围、捐赠政策）已在 changelog / 提交说明中记录  
- [ ] 捐赠接受者已了解税务申报义务（见 `数据来源与许可.md` §13.3）

## F. 建议律师审阅的情形

- 首次对外商业许可或收费 SaaS  
- 在应用商店上架并收费  
- 客户要求 indemnity（赔偿保证）或独家授权  
- 涉及境外分发或多司法辖区  
- 年度捐赠收入超过所在司法辖区免税额度
