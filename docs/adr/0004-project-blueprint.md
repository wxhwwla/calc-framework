# ADR-0004：项目统一蓝图 — 从计算器到平台的演进

**状态**：已批准  
**日期**：2026-05-28  
**决策者**：维护者  
**影响范围**：整个仓库；`framework/`、`endfield_damage_calculator/`、云端服务（远期）

---

## 1. 概述

本文档融合两条路线：
- **产品蓝图**（维护者提供）：四阶段演进——固本 → 培元 → 破圈 → 平台化
- **框架路线**（ADR-0003）：通用计算框架的模块化抽象——DAG 引擎 → 数据引擎 → 声明式 UI → 独立包

两条路线高度互补。框架路线为产品蓝图的**阶段四（平台化）**提前构建基础设施；产品蓝图为框架路线提供**用户价值驱动**和**商业化方向**。

核心使命不变：成为《明日方舟：终末地》及相关游戏玩家首选的配装决策平台。绝对底线：只读分析，不触碰任何写入游戏或模拟用户操作的"外挂"红线。

---

## 2. 四阶段蓝图（产品视角）

### 阶段一：固本 — 体验与稳定

**目标**：修复核心体验问题，不引入复杂新功能。

| # | 改动项 | 措施 | 价值 |
|---|--------|------|------|
| 1 | 修复界面卡死 | 耗时计算从 `ThreadPoolExecutor` 迁移到 `QThread`，通过信号/槽与 GUI 通信 | 消除"未响应"，工具感觉专业 |
| 2 | 计算任务管理 | "开始/停止"按钮 + 进度条，允许随时取消计算 | 用户对耗时计算有掌控感 |
| 3 | 本地并行优化 | `ThreadPoolExecutor` → `ProcessPoolExecutor`，多核并行，规避 GIL | 千万级遍历效率提升数倍 |

**完成后形态**：响应极快、计算高效的顶级桌面计算器。

### 阶段二：培元 — 云端能力与商业化

**目标**：构建云端服务，将计算能力外延。

| # | 改动项 | 措施 | 价值 |
|---|--------|------|------|
| 1 | 官方云函数 | 核心计算逻辑打包为云函数（AWS Lambda），提供 HTTP API | 计算卸载到云端，秒级出结果 |
| 2 | 混合计算模式 | 设置中增加"计算引擎"选项：本地引擎（免费）/ 云端引擎（付费） | 打开商业化大门 |
| 3 | 用户自定义 API | 极客用户可填入自己的云函数端点与 API Key | 降低项目方成本 |

**完成后形态**：多端可用、具备商业变现能力的 SaaS 化计算平台雏形。

### 阶段三：破圈 — OCR 杀手功能

**目标**：引入 OCR 技术降低数据录入门槛。

| # | 改动项 | 措施 | 价值 |
|---|--------|------|------|
| 1 | 桌面端截图助手 | PySide6 中增加"截图导入"按钮，手动框选属性位置，Tesseract OCR 识别 | 手动录入痛点被解决 |
| 2 | 种子数据集 | 匿名化收集用户框选坐标与截图（明确告知并获同意） | 为 YOLO 模型积累训练数据 |
| 3 | 云端 YOLO 模型 | 训练 YOLO 模型部署到云函数，"一键全自动识别" | 截图到填入全流程自动化 |

**完成后形态**：体验流畅、数据录入极其智能的现代化桌面工具，具备破圈传播潜力。

### 阶段四：平台化 — 生态与社区

**目标**：从单一游戏工具抽象为多游戏平台。

| # | 改动项 | 措施 | 价值 |
|---|--------|------|------|
| 1 | 自定义乘区公式 | 动态表单 + 安全表达式解析器，用户可定义新游戏公式，导出 JSON 分享 | 从专精工具变为可扩展数值平台 |
| 2 | 数据适配器框架 | 数据加载层抽象为适配器接口，为不同游戏编写独立适配器 | 正式支持多款游戏 |
| 3 | 开发者社区 | 开放适配器与乘区配置贡献指南，吸引技术型玩家贡献 | 自生长的生态系统 |

**完成后形态**：游戏数值工具领域的"标准"，社区驱动的内容生态。

```

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
阶段四 ─ 自定义乘区公式  ←→  ADR-0003 Phase 1  DAG 引擎     ✅
阶段四 ─ 数据适配器框架  ←→  ADR-0003 Phase 2  数据引擎     ✅
阶段四 ─ JSON 配置分享   ←→  ADR-0003 Phase 3  声明式 UI    ✅
阶段四 ─ 可视化编辑器    ←→  ADR-0003 Phase 3  editor/      ✅
阶段四 ─ 社区生态        ←→  ADR-0003 Phase 4  独立包+生态  ✅
阶段一 ─ QThread 迁移    ←→  (无对应 — 纯产品决策)          ❌
```
