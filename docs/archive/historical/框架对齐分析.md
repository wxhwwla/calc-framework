## 2. 终末地 — ✅ 完全对齐（2026-06-03）

| 维度 | 状态 | 说明 |
|------|:----:|------|
| `framework_bridge.py` | ✅ | 薄桥接层，GUI 通过此模块访问框架 |
| ComputeSheet + `layout.json` | ✅ | 13 个 section，覆盖全部 15 乘区 |
| `calc/dag_adapter/` | ✅ | DAG ↔ zone_snapshot + search + incoming + manual_buff 双向桥接 |
| 搜索管道 | ✅ | `evaluate_task()` → `evaluate_search_damage()` |
| 处决伤害 | ✅ | `calculate_execute_damage()` → `evaluate_search_damage()` + `execution_damage()` |
| 受击伤害 | ✅ | `enemy_burn_tick_damage()` → `evaluate_search_damage(damage_pipeline="abnormal")` |
| 多技能搜索 | ✅ | `multi_skill/optimizer/search.py` → `evaluate_search_damage()` |
| 手动 Buff（物理/法术） | ✅ | `manual_buff/physical.py` + `spell.py` → `evaluate_search_damage()` |
| 生存估算 | ⚠️ 基础公式 | 独立实现，不涉及框架引擎 |
| 框架搜索接口 | ✅ | `EndfieldSearchEngine` 实现 `SearchEngine` ABC，内部已调用 DAG 桥接 |

终末地 15 乘区计算**已全部迁移到 DAG 引擎**，不再存在双计算路径。所有调用均经过 `framework/adapters/endfield/functions.py` 中注册的 DAG 可调用函数。

作为迁移的副产品，框架扩展了两个新能力：

| 新增 | 位置 | 用途 |
|------|------|------|
| `compute_15_zone_detail()` | `framework/adapters/endfield/functions.py` | 返回各乘区明细字典（供 GUI 乘区饼图使用） |
| `DamageEvalResult` | `games/endfield/calc/dag_adapter/search_evaluate.py` | 替代 `DamageResult` 的数据类，含 `final_damage` + `zone_values` |
| `evaluate_search_damage` 参数默认值 | `search_evaluate.py` | 所有参数均有默认值（匹配 `DamageContext` 默认值） |

本地引擎 `calculate_single_hit_damage` 仍保留定义（`games/endfield/calc/damage/engine/calculate.py`），但**仅作为 reference 实现**，不在任何生产路径或 GUI 显示路径中被调用。
