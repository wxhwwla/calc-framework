### 4.183 Rust 搜索加速扩展（2026-06-16，已完成）

**背景**：全量搜索 evaluate_search_damage 的纯 Python 实现成为性能瓶颈（JSON 读取、FloorFormulaFitter._search 递归、2000x500x90 数据规模）。

**解决方案**：用 PyO3/maturin 创建 Rust 扩展 extensions/rust_search/，保留 Python 降级路径。

**Rust 扩展文件结构**：
- `evaluate_batch.rs` — 批量评估引擎
- `inverse.rs` — 公式拟合加速
- `lib.rs` — PyO3 桥接

**调用方式**：
| 方式 | 函数 | 适用场景 |
|------|------|----------|
| **A** 纯 Python | 原 evaluate_search_damage | 调试/降级 |
| **B** 批量 FFI | `evaluate_search_damage_batch` + `task_batch.py` | GUI/MVP 每 1000 条一次 Rust 调用 |

**降级机制**：`RUST_SEARCH_FALLBACK=1` 或 Rust 导入失败 → 纯 Python。

### 4.184 消除 PowerShell 闪窗（2026-06-16，已完成）

**问题**：搜索启动时 launcher 调用 `_detect_physical_cores()` 使用 `subprocess` 调用 PowerShell 命令，导致每次启动弹出黑色 PowerShell 窗口。

**解决方案**：将 `games/endfield/gui/controls/search/search_settings.py` 中的 `_detect_physical_cores()` 调用 `subprocess` 改为调用 `utils/platform_win32_patch.get_physical_processor_count()`，后者通过 `kernel32.GetLogicalProcessorInformation` Win32 API 获取核心数，无窗口弹出。

**涉及文件**：
- 新增 `utils/platform_win32_patch.py`
- 修改 `games/endfield/gui/controls/search/search_settings.py`

### 4.190 搜索性能瓶颈分析与优化方案（2026-06-26，**已规划待执行**）

**背景**：全量搜索 2500 万组合耗时约 60 秒，多核比单核更慢。用户要求分析瓶颈并给出优化方案。

**瓶颈诊断**：

| 瓶颈 | 位置 | 原因 | 耗时占比 |
|------|------|------|---------|
| Python 预处理 | `rust_bridge.py:_preprocess_for_rust()` | 每个任务创建 `DamageContext`、调用 `_collect_effects()`、字符串匹配 | ~70% |
| 线程锁 | `_rust_call_lock` | 所有线程串行化等待 Rust | ~15% |
| 对象分配 | 每次评估 | 创建 `DamageEffect`、`DamageContext`、列表推导 | ~15% |

**为什么多核更慢**：
1. 任务太轻（几十纳秒），线程分配/同步开销（微秒级）吃掉并行红利
2. `_rust_call_lock` 让多线程排队单核干活
3. ProcessPoolExecutor 在 Windows spawn 模式下开销更大

**优化方案（3 步）**：
1. **效果类型整数化** — 将字符串匹配改为 `u8` 整数 ID 匹配
2. **SoA 批量传参** — 预计算为 flat vectors，一次传入 Rust，零 Python 调用
3. **装备数据 SoA + 位运算套装检测** — 用位掩码检测套装触发

**预期效果**：60s → 1-2s（30-60x 加速）

**详细计划**：`.trae/plans/搜索性能优化计划.md`

**状态**：已写好计划文件，等待执行。

### 7.1 框架概述

三层自动化测试框架，用于验证 Web 前端、桌面应用、打包后 exe 的功能完整性：

| 层 | 工具 | 测试内容 |
|----|------|----------|
| Web 前端 | Cypress E2E | 页面渲染、交互、功能完整性 |
| 桌面应用 | pywinauto + 截图 | PySide6 GUI 启动、控件操作、功能可用性 |
| 打包后 exe | pywinauto + 截图 | PyInstaller 打包后是否崩溃、功能是否缺失 |

### 7.2 使用方式

```powershell
# 安装依赖
pip install -r scripts/auto_test/requirements.txt

# 一键运行所有测试
python scripts/auto_test/run_all.py

# 只运行某一层
python scripts/auto_test/web_test.py        # Web 测试
python scripts/auto_test/desktop_test.py    # 桌面应用测试
python scripts/auto_test/packaged_test.py   # 打包后测试

# 跳过某一层
python scripts/auto_test/run_all.py --skip-web
python scripts/auto_test/run_all.py --skip-desktop
python scripts/auto_test/run_all.py --skip-packaged
python scripts/auto_test/run_all.py --skip-build  # 跳过打包步骤
```
