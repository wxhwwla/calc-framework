# 依赖说明

> 单一事实来源：运行时与测试以 [`endfield_damage_calculator/pyproject.toml`](../endfield_damage_calculator/pyproject.toml) 为准；打包以 [`build.py`](../endfield_damage_calculator/build.py) 为准。

## 1. Python 包（`[包]` / `pip install -e`）

| 类别 | 声明位置 | 内容 | 谁需要 |
|------|----------|------|--------|
| **运行时** | `[project].dependencies` | `customtkinter>=5.2.2` | GUI、`main.py`、所有乘区计算 |
| **开发** | `[project.optional-dependencies].dev` | `pytest>=8.0` | 本地测试、GitHub Actions CI |
| **打包** | `[project.optional-dependencies].build` | `pyinstaller>=6.0` | 仅执行 `python build.py` |

### 传递依赖（未写入 pyproject，由 pip 自动安装）

CustomTkinter / PyInstaller 会间接引入例如 **Pillow**、**darkdetect**、**numpy**、PyPI 的 **packaging** 等。发布前可用：

```powershell
cd endfield_damage_calculator\endfield_damage_calculator
pip install -e ".[build]"
pip freeze > ..\..\dist-deps-lock.txt   # 本地核对用，勿提交若未纳入流程
```

第三方许可见 [`NOTICES.md`](../NOTICES.md)。

### 切勿使用的模块名

| 错误做法 | 原因 |
|----------|------|
| 在本仓库新建顶层包 `packaging/` | 遮蔽 PyInstaller 依赖的 PyPI `packaging`，导致 `No module named 'packaging.requirements'` |
| `--exclude-module packaging` | 同上，会排除 PyInstaller 需要的库 |

发布布局代码在 **`release_bundle/`**（见 `release_bundle/release_layout.py`）。

## 2. 标准库与仓库内模块

| 模块 | 依赖 |
|------|------|
| `calculation.*` | 仅标准库 |
| `data.loader` | 标准库 + `utils.path_utils` + 旁路 JSON 文件 |
| `gui_design.*` | `customtkinter`、`data.loader`、`legal` |
| `scripts/*` | 开发维护用，**不**打入 exe（`build.py` 已 exclude） |
| `tests/*` | `pytest`、`[dev]` |

## 3. 打包（`build.py`）

| 项 | 说明 |
|----|------|
| 工具 | PyInstaller **onedir**（非 onefile） |
| 数据 | **不**写入 exe；由 `release_bundle.stage_release_folder` 复制 JSON + `DATA_LICENSE` 等到 `dist/终末地伤害计算器/` |
| 加载 | 运行时 `get_resource_path()` 读 exe **同级** JSON |
| 排除模块 | `tests`、`scripts`、`release_bundle`、`add_character`、`add_weapon`、`test_` |

`pyproject.toml` 中已删除过时的 `[tool.pyinstaller]` onefile + 内嵌 datas 配置。

## 4. 仓库根与其它目录

| 路径 | 依赖 | 安装方式 |
|------|------|----------|
| `[根]` `github_upload_module.py` | 标准库 + Git | 无需 pip 包 |
| `[工具]` `tools/bwiki_scout/` | 标准库；同步时临时加入 `[包]` 路径以用 `calculation.inverse` | 不列入 pyproject；见 [`tools/bwiki_scout/README.md`](../tools/bwiki_scout/README.md) |
| `[工具]` `tools/audit/` | PowerShell / `gh` | 独立 |

## 5. CI（`.github/workflows/ci.yml`）

- 仅 `pip install -e ".[dev]"` + `pytest`
- **不**安装 `[build]`，不在 CI 内打 exe

## 6. 快速命令

```powershell
cd endfield_damage_calculator\endfield_damage_calculator
pip install -e ".[dev]"          # 开发 + 测试
pip install -e ".[build]"        # 打包
pip install -e ".[dev,build]"    # 一次装齐
python -m pytest tests/ -q
python build.py
```
