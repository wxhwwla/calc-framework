# 依赖说明

> 单一事实来源：运行时与测试以 [`games/endfield/pyproject.toml`](../games/endfield/pyproject.toml) 为准；打包以 [`scripts/main_build.py`](../scripts/main_build.py) 为准（旧 `build.py` 已重导向至此）。

## 1. Python 包（`[包]` / `pip install -e`）

| 类别 | 声明位置 | 内容 | 谁需要 |
|------|----------|------|--------|
| **运行时** | `[project].dependencies` | `customtkinter`、`matplotlib` | GUI、伤害仪表盘、乘区计算 |
| **插件 YAML** | `[plugins]` | `pyyaml>=6.0` | `plugins/enemies/*.yaml`；JSON 插件无需 |
| **可视化/绘图** | `[viz]` | 同 matplotlib | 仅兼容旧命令 `pip install -e ".[viz]"` |
| **PySide6** | `[qt]` | `PySide6>=6.6` | **默认后端的运行时依赖**。当前通过 `ENDFIELD_UI_BACKEND` 环境变量切换（`qt` 默认，`ctk` 可回退） |
| **开发** | `[dev]` | `pytest`、`matplotlib`、`pyyaml` 等 | 本地测试、GitHub Actions CI |
| **打包** | `[project.optional-dependencies].build` | `pyinstaller>=6.0` | 执行 `python scripts/main_build.py`（支持 `--target launcher`/`calculator`/`designer`/`arknights` 等） |

自检（仓库根目录）：`python tools/check_optional_deps.py`

### 开发模式启动（`main.py`）

| 项 | 说明 |
|----|------|
| 安装 | 新 venv 须 `pip install -e .` 或 `pip install -e ".[dev]"` |
| 缺依赖 | `ensure_runtime_dependencies()` **只打印警告**，不阻塞 GUI、不在启动时同步 pip |
| Windows | `main.py` / `gui.py` 及**所有顶层 import CTk 的 GUI 子模块**在 import CTk 前调用 `platform_win32_patch`（规避 WMI 卡死；PyInstaller Analysis 会单独 import 子模块） |
| 冻结 exe | `sys.frozen` 时不做依赖提示；matplotlib 由 `main_build.py` 打入发布包 |

### 传递依赖（未写入 pyproject，由 pip 自动安装）

CustomTkinter / PyInstaller 会间接引入例如 **Pillow**、**darkdetect**、**numpy**、PyPI 的 **packaging** 等。发布前可用：

```powershell
cd games/endfield
pip install -e ".[build]"
pip freeze > ..\..\dist-deps-lock.txt   # 本地核对用，勿提交若未纳入流程
```

第三方许可见 [`NOTICES.md`](../NOTICES.md)。

### 切勿使用的模块名

| 错误做法 | 原因 |
|----------|------|
| 在本仓库新建顶层包 `packaging/` | 遮蔽 PyInstaller 依赖的 PyPI `packaging`，导致 `No module named 'packaging.requirements'` |
| `--exclude-module packaging` | 同上，会排除 PyInstaller 需要的库 |

发布布局代码在 **`release_bundle/`**（见 `release_bundle/release_layout.py`）。

## 3. 打包（`scripts/main_build.py`）

发布文件夹除 exe 与 `character_weapon_equipment/**/*.json`（含 `equipments.json`）外，运行全量/MVP 搜索后会在 **exe 同级** 生成 `search_output/`（用户数据，非仓库提交）。见 `release_bundle/release_layout.py` 与 `发布说明.txt`。

| 项 | 说明 |
|----|------|
| 工具 | PyInstaller **onedir**（非 onefile）；子进程入口 `release_bundle/pyinstaller_entry.py` |
| 数据 | **不**写入 exe；由 `release_bundle.stage_release_folder` 复制 JSON + `DATA_LICENSE` 等到 `dist/` |
| matplotlib | 打包前 `check_build_dependencies()` 检查；`--collect-all matplotlib` + `backend_tkagg` |
| Windows | `main_build.py` 与 PyInstaller 子进程均先 `apply_platform_win32_patch()` |
| 看门狗 | 默认超时 1200s、心跳 15s；环境变量 `ENDFIELD_BUILD_TIMEOUT_SECONDS` / `ENDFIELD_BUILD_HEARTBEAT_SECONDS` |
| 加载 | 运行时 `get_resource_path()` 读 exe **同级** JSON |
| 排除模块 | `tests`、`scripts`、`release_bundle`、`add_character`、`add_weapon`、`test_` |

### 3.1 构建目标

| 目标 | 命令 | 输出目录 |

## 6. 快速命令

```powershell
cd games/endfield
pip install -e ".[dev]"          # 开发 + 测试
pip install -e ".[build]"        # 打包
pip install -e ".[dev,build]"    # 一次装齐
python -m pytest tests/ -q
python scripts/main_build.py --target launcher   # 打包统一启动器（推荐）
python scripts/main_build.py                     # 打包计算器
```
