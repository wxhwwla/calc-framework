## 优化记录（2026-11-03）

- **瓶颈**：`rust_full` 的约 28s 中有约 27s 花在 Python 侧 `_precompute_final_attacks_for_batch` 逐组合重算最终攻击力，Rust 伤害评估仅 1–3s。
- **原因**：最终攻击力只依赖装备的 `攻击力`、角色主/副能力值、`攻击力%` 四个数，但 973,728 个组合中只有约 56,454 个唯一签名（约 5.8%）；原实现每个组合都重走完整乘区链，并重复解析武器技能选用状态。
- **修改**：按 `(攻击力, 主能力, 副能力, 攻击力%)` 记忆化最终攻击力，缓存按武器分隔；武器技能选用状态每把武器只解析一次。回归测试见 `games/endfield/tests/calculation/search/evaluate/test_full_batch_precompute.py`。
- **结果**：`rust_full` 28.36s → **9.75s**（约 2.9×），达成 `<10s` 目标；TopN 与三模式一致性保持 ✅。
