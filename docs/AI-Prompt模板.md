# AI Prompt 模板

## 这个文件是干什么的

你不懂框架结构也没关系，复制下面的 prompt 到任何 AI 聊天工具里，它就能帮你生成计算器文件。

## 使用方式

1. 把 prompt 复制到 ChatGPT/Claude 等 AI 中
2. 把 `[ ]` 中的内容替换成你的游戏信息
3. AI 会输出一组文件，把这些文件放到 `framework/adapters/{你的游戏}/` 目录下

## 模板一：通用公式计算器（适合大多数RPG）

```
你是一个游戏伤害计算器生成器。请为以下游戏生成完整的适配器文件。

游戏名称：[你的游戏名]
游戏类型：[RPG / 射击 / MOBA / 其他]

伤害公式描述：
[在这里描述你的伤害公式，比如"最终伤害 = 攻击力 × 技能倍率 × (1 + 伤害加成) × (1 - 防御/(防御+100)) × (是否暴击 ? 1 + 暴击伤害 : 1)"]

角色/武器属性列表：
- [属性1]: [说明]，来源：[角色/武器/敌方]
- [属性2]: [说明]，来源：[角色/武器/敌方]
...

用户可输入的参数：
- [参数1]: [说明]，默认值
- [参数2]: [说明]，默认值

需要输出的结果：
- [结果1]: [说明]
- [结果2]: [说明]

请生成以下文件（用代码块输出，每个文件独立）：
1. meta.json - 适配器元数据
2. {game}.dag.json - DAG 计算图
3. attr_schema.json - 属性定义
4. functions.py - 自定义函数（如有）
5. ui/layout.json - UI 布局
```

## 模板二：从 Wiki 数据创建（适合有 Wiki 的游戏）

```
你是一个游戏伤害计算器生成器。

我提供了以下 Wiki 页面内容，请帮我提取游戏数据并生成计算器。

Wiki 页面内容：
[粘贴 Wiki 页面的文本内容]

游戏名称：[你的游戏名]

请：
1. 从 Wiki 内容中提取角色/武器/属性数据
2. 识别伤害公式（如果 Wiki 中有）
3. 生成完整的适配器文件：
   - meta.json
   - {game}.dag.json
   - attr_schema.json
   - functions.py（如有）
   - ui/layout.json
```

## 模板三：从数据表格创建（适合有 Excel/CSV 数据）

```
你是一个游戏伤害计算器生成器。

我提供了以下游戏数据表格，请帮我生成计算器。

数据表格：
[粘贴 CSV/表格数据]

游戏名称：[你的游戏名]
伤害公式：[描述公式]

请生成完整的适配器文件：
1. meta.json
2. {game}.dag.json
3. attr_schema.json
4. functions.py（如有）
5. ui/layout.json
6. data/characters.json（从表格提取的角色数据）
```

## 模板四：FPS 射击游戏专用

```
你是一个游戏伤害计算器生成器。请为以下 FPS 游戏生成适配器。

游戏名称：[游戏名]

武器数据：
[列出武器名称、基础伤害、射速、弹匣容量、换弹时间]

距离衰减：
[描述衰减曲线，如"10米内满伤，10-30米线性衰减到50%，30米以上固定30%"]

部位倍率：
- 头部：[倍率]
- 胸部：[倍率]
- 腹部：[倍率]
- 四肢：[倍率]

护甲减伤公式：[描述]

请生成 fps 品类模板风格的计算器文件。
```

## 模板五：多乘区 RPG 专用

```
你是一个游戏伤害计算器生成器。请为以下多乘区 RPG 游戏生成适配器。

游戏名称：[游戏名]

攻击力公式：[如"基础攻击 × (1 + 攻击力%) + 固定攻击"]

乘区列表（每个乘区是独立相乘的）：
1. [乘区1名称]: [计算方式]
2. [乘区2名称]: [计算方式]
3. [乘区3名称]: [计算方式]
...

角色属性：[列出所有属性]
用户输入参数：[列出用户需要输入的参数]

请使用 multi-zone 品类模板风格，每个乘区作为一个 subgraph。
```

## 使用提示

- 模板一适合大多数情况，优先使用
- 如果有 Wiki 但爬虫不好使，用模板二粘贴页面内容
- 如果有一大堆数值，用模板三更高效
- FPS 和 多乘区 RPG 有专门的模板，结果更准确
- AI 输出的文件可能有格式问题，如果报错把报错信息发给 AI 让它修
