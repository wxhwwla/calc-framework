# 框架适配新游戏 — 从零到完整计算器

本文档指导开发者使用 calc-framework 为一款新游戏创建完整的数值计算适配包。
读完本文你将能：创建 DAG 公式 → 设计 UI 布局 → 打包为 `.calcpack` → 用 CalcPackViewer 加载运行。

---

## 一、框架全景

```
┌──────────────────────────────────────────────────────────────┐
│                    calc-framework (核心引擎)                   │
│  DAG 求值引擎  ·  搜索枚举引擎  ·  插件注册表  ·  主题管理器    │
│  ComputeSheet  ·  CalcPackViewer  ·  布局/图编辑器            │
└────────────────────┬─────────────────────────────────────────┘
                     │  adapter discover (自动发现)
     ┌───────────────┼───────────────┐
     ▼               ▼               ▼
┌──────────┐  ┌──────────┐  ┌──────────┐
│ endfield │  │ card_rpg │  │ 你的游戏  │  ← 你在这里
│ 适配包    │  │ 适配包    │  │ 适配包    │
└──────────┘  └──────────┘  └──────────┘
```

每个适配包是一个独立目录，放在 `framework/adapters/` 下，框架启动时自动发现。
一个适配包 = **公式定义** + **变量描述** + **UI 布局** + **自定义函数** + **可选数据文件**。

## 二、创建适配包 — 最小步骤

### 2.1 目录结构

在 `framework/adapters/` 下创建你的游戏目录：

```
framework/adapters/your_game/
├── meta.json              # 适配包元信息（必需）
├── your_game.dag.json     # DAG 公式定义（必需）
├── attr_schema.json       # 变量属性描述（推荐）
├── functions.py           # 自定义纯函数（可选）
├── ui/
│   └── layout.json        # UI 布局定义（推荐）
└── data/                  # 游戏数据文件（可选）
    ├── characters.json
    ├── weapons.json
    └── ...
```

### 2.2 meta.json — 适配包身份证

```json
{
  "name": "你的游戏名称",
  "game": "你的游戏",
  "version": "1.0.0",
  "schema_version": "dag-v1",
  "entry_dag": "your_game.dag.json",
  "description": "简短描述",
  "author": "你的名字",
  "tags": ["rpg", "strategy"],
  "attr_schema": "attr_schema.json",
  "functions": {
    "clamp": "functions.py",
    "lerp": "functions.py"
  }
}
```

| 字段 | 必填 | 说明 |
|------|------|------|
| `name` | ✅ | 适配包显示名 |
| `entry_dag` | ✅ | 入口 DAG 文件名 |
| `schema_version` | ✅ | 固定 `dag-v1` |
| `attr_schema` | ❌ | 变量属性描述文件路径 |
| `functions` | ❌ | 自定义函数注册表 |

### 2.3 DAG 公式 — 定义数值计算

DAG（有向无环图）是框架的核心。你定义节点和连线，引擎自动拓扑排序求值。

**示例：攻击力公式**

```json
{
  "schema_version": "dag-v1",
  "name": "攻击力计算链",
  "description": "最终攻击力 = (角色基础 + 武器基础) × (1 + 攻击力%) + 附加攻击",
  "variables": {
    "character.base_atk": {
      "type": "float", "source": "character",
      "default": 100, "description": "角色基础攻击力"
    },
    "weapon.base_atk": {
      "type": "float", "source": "weapon",
      "default": 50, "description": "武器基础攻击力"
    },
    "weapon.atk_pct": {
      "type": "float", "source": "weapon",
      "default": 0.15, "description": "攻击力%加成"
    },
    "weapon.flat_atk": {
      "type": "float", "source": "weapon",
      "default": 10, "description": "附加攻击力"
    }
  },
  "nodes": {
    "char_val":    { "type": "var",  "path": "character.base_atk" },
    "weapon_val":  { "type": "var",  "path": "weapon.base_atk" },
    "atk_pct":     { "type": "var",  "path": "weapon.atk_pct" },
    "flat_val":    { "type": "var",  "path": "weapon.flat_atk" },
    "const_1":     { "type": "const", "value": 1.0 },
    "base_sum":    { "type": "binary", "op": "+", "lhs": "char_val", "rhs": "weapon_val" },
    "pct_mult":    { "type": "binary", "op": "+", "lhs": "const_1", "rhs": "atk_pct" },
    "base_x_pct":  { "type": "binary", "op": "*", "lhs": "base_sum", "rhs": "pct_mult" },
    "final_atk":   { "type": "binary", "op": "+", "lhs": "base_x_pct", "rhs": "flat_val" }
  },
  "outputs": {
    "最终攻击力": { "node": "final_atk", "label": "最终攻击力", "is_primary": true }
  }
}
```

**节点类型速查表：**

| 类型 | 标识 | 说明 |
|------|------|------|
| 常量 | `const` | 固定数值，`"value": 3.14` |
| 变量引用 | `var` | 引用外部输入，`"path": "character.atk"` |
| 二元运算 | `binary` | `+` `-` `*` `/` `^` `min` `max` `mod` |
| 一元运算 | `unary` | `floor` `ceil` `abs` `sqrt` `neg` `ln` `log10` `sin` `cos` `tan` |
| 条件分支 | `condition` | 三输入：条件/真值/假值 |
| 表达式 | `expr` | 内联 Python 表达式，如 `"max(0, a - b)"` |
| 子图调用 | `call` | 引用另一个 subgraph，`"ref": "block_id"` |
| 输出标记 | `output` | 标记计算结果为输出 |

### 2.4 attr_schema.json — 变量属性描述

描述每个变量的 UI 展示方式（用于 ComputeSheet 自动推断控件）：

```json
{
  "attributes": [
    { "name": "character.base_atk", "type": "float", "source": "character",
      "default": 100, "description": "角色基础攻击力" },
    { "name": "weapon.base_atk", "type": "float", "source": "weapon",
      "default": 50, "description": "武器基础攻击力" }
  ]
}
```

| 字段 | 说明 |
|------|------|
| `name` | 变量全路径，与 DAG variables 中的 key 一致 |
| `type` | `float` / `int` / `bool` |
| `source` | 来源分类，用于 UI 分组 |
| `default` | 默认值 |
| `description` | 展示说明 |

### 2.5 functions.py — 自定义纯函数

如果 DAG 内置节点不够用，可以注册自定义函数：

```python
# framework/adapters/your_game/functions.py

def clamp(value: float, low: float, high: float) -> float:
    return max(low, min(high, value))

def lerp(a: float, b: float, t: float) -> float:
    return a + (b - a) * t
```

在 `meta.json` 中注册后，DAG 节点可以通过 `"type": "call"` 引用：

```json
{
  "type": "call",
  "function": "clamp",
  "inputs": { "value": "some_node", "low": "const_0", "high": "const_100" }
}
```

### 2.6 UI 布局 — 告诉框架怎么展示

`layout.json` 定义计算器的界面结构。框架据此自动渲染控件：

```json
{
  "schema_version": "ui-v1",
  "sections": [
    {
      "id": "character",
      "type": "inputs",
      "title": "角色参数",
      "columns": 2,
      "variables": [
        "character.base_atk",
        "character.hp",
        "character.def"
      ]
    },
    {
      "id": "weapon",
      "type": "inputs",
      "title": "武器参数",
      "variables": [
        "weapon.base_atk",
        "weapon.atk_pct",
        "weapon.flat_atk"
      ]
    },
    {
      "id": "results",
      "type": "outputs",
      "title": "结算结果",
      "outputs": [
        "最终攻击力",
        "最终伤害"
      ]
    }
  ]
}
```

| 字段 | 说明 |
|------|------|
| `type` | `inputs`（输入区）或 `outputs`（结果区） |
| `columns` | 拆列数（默认 1） |
| `variables` | 输入区的变量引用，与 DAG variables key 一致 |
| `outputs` | 结果区的输出引用，与 DAG outputs key 一致 |

## 三、完整工作流——从公式到可运行计算器

### 步骤 1：用图编辑器可视化搭建 DAG

```bash
python -m calc_framework.graph_editor
python -m calc_framework.graph_editor path/to/graph.json   # 启动即加载
```

- 从左侧面板拖拽节点到画布
- 从输出端口连线到输入端口
- 双击复合节点进入子图
- 工具栏「运算」按钮实时求值
- 工具栏「保存」导出为 `.json`

也可直接手写 JSON（见 §2.3）。

### 步骤 2：用布局编辑器设计 UI

```bash
python -m calc_framework.editor --dag path/to/dag.json
```

布局编辑器读取 DAG 变量，三栏操作：
- **左栏**：DAG 变量列表
- **中栏**：Section 管理（添加/删除/排序输入输出节）
- **右栏**：变量拖拽到 Section，调整列数

完成 → 导出 `.calcpack`（ZIP 包，含 DAG + 布局 + 数据）。

### 步骤 3：用 CalcPackViewer 验证

```bash
devtool.py launcher
# 或直接用框架包：
python -c "from calc_framework.ui.viewer import open_calcpack; open_calcpack('output/你的包.calcpack')"
```

CalcPackViewer 自动：
1. 读取 DAG 变量 → 渲染输入控件
2. 读取 UI 布局 → 组织 Section
3. 实时求值 → 显示所有输出
4. 支持实体选择（如果有数据文件）

### 步骤 4：编写适配器测试

参考已有适配器测试：`framework/tests/adapters/test_card_rpg_adapter.py`

```python
# tests/adapters/test_your_game_adapter.py
from calc_framework.config.adapter import AdapterPackage
from calc_framework.config.manager import discover_adapters

def test_adapter_discovered():
    adapters = discover_adapters()
    assert "你的游戏名称" in adapters

def test_adapter_load_and_evaluate():
    adapter = AdapterPackage.load("你的游戏名称")
    assert adapter is not None
    context = {
        "character.base_atk": 100,
        "weapon.base_atk": 50,
        "weapon.atk_pct": 0.15,
        "weapon.flat_atk": 10,
    }
    result = adapter.evaluate(context)
    assert result is not None
    assert "最终攻击力" in result.outputs
```

### 步骤 5：打包发布

适配包是独立目录，可直接分享：

```bash
# 方式一：复制目录
cp -r framework/adapters/your_game /分享路径/

# 方式二：打包为 .calcpack（含数据）
python -m calc_framework.editor --dag path/to/dag.json   # 导出为 .calcpack

# 方式三：发布到 Calc Hub
# 在 GitHub 提交 PR 到 web/hub/，更新 catalog.json
```

其他用户将适配包放入 `framework/adapters/` 即可使用。

## 四、进阶功能

### 4.1 复合节点与子图

复杂 DAG 可拆分为多个 subgraph：

```json
{
  "subgraphs": {
    "attack_block": {
      "parameters": ["base", "pct", "flat"],
      "nodes": {
        "sum": { "type": "binary", "op": "+", "lhs": "$base", "rhs": "$flat" },
        "result": { "type": "binary", "op": "*", "lhs": "sum", "rhs": "$pct" }
      },
      "output_node": "result"
    }
  },
  "nodes": {
    "atk": { "type": "call", "ref": "attack_block",
             "inputs": { "base": "char_val", "pct": "atk_pct_mult", "flat": "flat_val" } }
  }
}
```

### 4.2 插件系统

游戏专属的规则逻辑可以封装为框架插件：

```python
from calc_framework.plugin.base import BasePlugin, PluginMeta

class YourGameCritPlugin(BasePlugin):
    @property
    def meta(self) -> PluginMeta:
        return PluginMeta(
            name="your_crit",
            version="1.0.0",
            description="你的游戏暴击规则",
            author="你",
        )

    def on_load(self) -> dict:
        return {
            "variables": { ... },
            "templates": {
                "crit_template": {
                    "parameters": ["rate", "dmg"],
                    "nodes": { ... },
                    "output_node": "result"
                }
            }
        }
```

内置插件注册后，GUI 菜单「工具 → 插件管理器」可查看。

### 4.3 OCR 截图识装

如果你游戏有固定的 UI 布局，可以用 OCR 管线免去手动输入：

1. 采集游戏截图 → `python -m tools.ocr.cli` 检测
2. 在 `tools/ocr/recognizer.py` 的 `GAME_TERMS` 字典添加你的游戏专有名词
3. 修改 `mapper.py` 的 `_load_game_data()` 加载你的数据
4. GUI 底栏「截图识装」按钮一键填入

### 4.4 主题定制

适配包可以自带主题。在 `.calcpack` 中包含 `ui/theme.json`：

```json
{
  "name": "你的游戏主题",
  "base": "dark",
  "colors": {
    "bg_primary": "#1a1a2e",
    "accent": "#e94560"
  },
  "font": { "family": "SimHei", "size": 12 }
}
```

加载时自动注册为 `calcpack` 主题并激活。

### 4.5 数据文件

适配包的数据文件放在 `data/` 下。框架的 `AdapterPackage` 提供 `open_data(path)` 方法访问包内数据：

```python
adapter = AdapterPackage.load("你的游戏")
data = adapter.open_data("characters.json")
```

CalcPackViewer 加载 `.calcpack` 后，会自动读取其中的数据文件作为实体选择来源。

## 五、完整适配包示例

### card_rpg（最简单的参考）

```
framework/adapters/card_rpg/
├── meta.json
├── card_rpg.dag.json      # 攻击 - 防御 = 伤害
├── attr_schema.json
├── functions.py            # clamp
├── loader.py               # 数据加载器
└── ui/
    └── layout.json         # 一个输入 Section + 一个输出 Section
```

核心公式：`伤害 = max(1, 攻击力 - 防御力) × 技能倍率`

启动命令：`python -c "from calc_framework.launcher import run_launcher; run_launcher('card_rpg')"`

### moba（带 DAG 子图的参考）

```
framework/adapters/moba/
├── meta.json
├── moba.dag.json           # 含 blocks 区块化定义
├── attr_schema.json
├── functions.py
├── loader.py
└── ui/
    └── layout.json
```

核心公式：`实际伤害 = 面板攻击 × 技能加成 × (1 - 护甲/(护甲+100))`

### endfield（最完整参考，15 乘区）

终末地适配器在 `games/endfield/` 下，含完整 15 乘区 DAG、
角色/武器/装备数据、全量搜索枚举引擎。新手建议从 card_rpg 或 moba 开始。

## 七、常见问题

**Q：需要修改框架核心代码吗？**
不需要。适配包是纯配置 + 自定义函数，框架自动发现和加载。

**Q：DAG 支持循环引用吗？**
不支持。DAG 是有向无环图，引擎执行拓扑排序，含循环时会报错。

**Q：可以在一个适配包中使用多个 DAG 文件吗？**
可以。用 `entry_dag` 指定主图，主图通过 `call` 节点引用其他图。

**Q：如何调试 DAG 求值结果？**
图编辑器工具栏「运算」按钮显示全部节点值，属性面板底部显示选中节点的实时预览。

**Q：框架和我的游戏如何分发？**
- 框架：`pip install calc-framework` 或直接复制 `framework/` 目录
- 适配包：独立目录，复制到 `framework/adapters/` 下即可
- 用户打包：`main_editor.py` 导出 `.calcpack` 供 CalcPackViewer 加载
