### 1.2 SSH（推送 / 拉取 GitHub）

1. 生成密钥并添加到 GitHub → Settings → SSH keys  
2. 若 22 端口不通，在 `~/.ssh/config` 配置：

```
Host github.com
    HostName ssh.github.com
    Port 443
    User git
```

3. 验证：`ssh -T git@github.com`

| 作用 | 说明 |
|------|------|
| 免 Token | `git remote` 使用 `git@github.com:...`，勿把 PAT 写进 URL |

### 1.3 GitHub CLI（可选）

```powershell

```

| 作用 | 说明 |
|------|------|
| 管理 Issue | 与 `docs/agents/issue-tracker.md` 约定一致 |

| 变量 | 文件 | 谁改 |

| `_VERSION` | `[包]/please_read_me.py` | 上传脚本自动 bump；重大版本第一位手改 |

### 3.2 批量录入示例武器

| 改数据 | 编辑 `_SEED_WEAPONS` 后重跑；写入 `weapons.json` |


| 作用 | 说明 |

通过 `[包]/character_weapon_equipment/character_data/add_character.py` 中的 `add_character()` 录入（与武器类似，需在 Python 或自建脚本中调用）。

| 作用 | 说明 |

| 生成曲线 | 按成长参数写入 `characters.json` |

**大改动（新武器库、新乘区等）上传 GitHub 时建议用 `--minor` 升版本（见 §5）。**

## 5. GitHub 上传与下载（`[根]`）

### 5.1 上传（推荐日常用这个）

```powershell
cd endfield_damage_calculator   # [根]
python github_upload_module.py
python github_upload_module.py --minor      # 第二位 +1：新武器/新乘区等
python github_upload_module.py --no-bump    # 提交推送但不改 _VERSION
```

| 步骤 | 作用 |
|------|------|
| 检测业务改动 | 仅有 `please_read_me.py` 改动时不 bump |
| 交互 P/M | 回车 = patch（第三位 +1）；输入 `M` = minor |
| 写总结块 | 在 `please_read_me.py` **底部**生成 `# --- UPLOAD_SUMMARY ---` |
| commit | 消息形如 `v1.9.1: 标题` + 改动列表（读总结块） |
| push 成功 | 删除底部总结块；**失败则保留**，版本不回滚 |
| 纯补推 | 仅有未 push 的 commit、无新改动 → **不** bump、不写总结 |

**不要**用裸 `git commit` + `git push` 代替上传脚本，否则 `_VERSION` 可能与远程不同步。

### 5.2 从远程覆盖本地（危险）

```powershell
cd endfield_damage_calculator   # [根]
python github_download_module.py
```

| 作用 | 说明 |
|------|------|
| 强制同步 | `reset --hard` 到 `origin/main`，**未提交改动会丢失** |
| 使用场景 | 换电脑、本地搞乱只想与远程完全一致 |

### 5.3 手动 Git（了解即可）

| 命令 | 作用 |
|------|------|
| `git status` | 查看改动 |
| `git remote -v` | 应显示 `git@github.com:...`，无嵌入 Token |
| `git push` | 仅补推时可用；新功能提交仍建议走上传脚本 |

## 7. 打包发布 exe（`[包]`）

### 7.1 打包前

1. 在 `please_read_me.py` **手动**修改 `_EXE_VERSION`（窗口标题与 exe 显示）  
2. 确认 `pip install setuptools wheel pyinstaller`

### 7.2 执行打包

```powershell
cd endfield_damage_calculator\endfield_damage_calculator   # [包]
python build.py
```

| 作用 | 说明 |
|------|------|
| 输出 | `dist/终末地伤害计算器.exe` |
| 勿提交 | `*.exe` 已在 `.gitignore` |

`_VERSION` 与 exe 版本**独立**：上传 GitHub 不会改 `_EXE_VERSION`。
