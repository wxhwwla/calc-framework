## 1. 优先级口径

| 级别 | 含义 | 处理期限 |
|------|------|----------|
| P0 | 安全边界、数据损坏、不可逆损失 | 立即，禁止带病发布 |
| P1 | 核心交付、合规或承诺失真 | 当前发布周期内 |
| P2 | 可维护性、可复现性、文档事实源 | 30 天内或随相关模块变更 |
| P3 | 持续治理、性能与历史债 | 90 天内复审 |

## 3. 例外与接受风险

- 接受风险必须在「开放债务登记」中标记 `accepted`，并写明理由、影响范围和复审日期。
- 涉及安全或合规的例外不得由单人静默接受，需在 `SECURITY.md` 或 `NOTICES.md` 留下可追溯说明。
- 例外到期未复审时，按 `open` 处理，并在下一次发布检查中阻断。

## 4. 复审节奏

- **每月**：更新状态、复审日期与阻塞原因；关闭已满足验收条件的条目。
- **每次发布前**：检查所有 P0/P1 条目；`open` / `in-progress` 的 P0 阻断发布。
- **每季度**：复核 `accepted` 条目与 CODEOWNERS 覆盖范围。
