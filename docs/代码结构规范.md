# 代码结构规范

> **约束来源**：[ADR-0001：代码目录与文件规模约束](adr/0001-code-layout-constraints.md)  
> **受众**：维护者、贡献者、Cursor Agent（新代码与重构均须遵守）

---

## 1. 两条铁律

### 1.1 目录宽度

- 任意目录下 **直接子项（文件 + 文件夹）≤ 20（硬顶）**；**目标 ≤ 15**（超过 15 时应规划拆分子目录）。
- **数子项时包括**：`.py`、子文件夹、`README.md` 等；**不包括** `__pycache__`、`.pytest_cache`。
- 第 **21** 个子项出现前，必须先建子目录并迁入，或合并相关文件。

### 1.2 文件长度

- **目标**：单个 `.py` **≤ 400 行**（可读、可测、可 review）。
- **硬顶**：业务/GUI/计算代码 **> 500 行不得新增**；已有超长文件列入迁移 backlog，拆分时优先动刀。
- **例外申请**：须在 PR 或 Issue 说明理由，并更新 ADR 或本文件 §5 豁免表。

## 3. 命名与拆分手法

1. **先按领域拆目录**，再按职责拆文件（与「一个文件夹里堆 20 个 utils」相反）。
2. 单类过大：用 **mixin** 或 **按 UI 区块拆模块**（本项目 `gui/shell/app_*.py` 为范例）。
3. 纯函数集合：独立 `*_lines.py` / `*_helpers.py`，由薄 `__init__.py` 或聚合模块 re-export。
4. **Import（方案 B）**：根路径 stub 已移除；**新代码禁止** `from gui.loadout_state` 等旧路径。
5. 注释语言：**中文**（与仓库约定一致）。
6. **拆分工具**：优先 `python tools/split_module_by_symbols.py --only soft|core`（AST 符号切分）；**禁止**行号硬切。
7. **GUI 字体规范**：所有 CTk/PySide6 控件（`CTkButton`/`CTkLabel`/`CTkEntry`/`CTkOptionMenu`/`CTkCheckBox`/`CTkSwitch`/`CTkComboBox`/`CTkTextbox`）必须在构造时显式传入 `font=` 参数。字体通过以下途径获取：
   - 主应用优先 `self.small_font` / `self.big_font`（`gui_fonts.default_ui_font()` 创建，族名与系统一致）
   - 独立模块用 `default_ui_font(size=...)` 直接调用
   - 全局兜底：`gui_settings.configure_tk_default_font(root)` 在根窗口创建后覆写 `TkDefaultFont` **和** `ThemeManager.theme["CTkFont"]["family"]`（后者是 CTkOptionMenu/CTkComboBox 下拉菜单 DropdownMenu 动态创建 `CTkFont()` 的默认族名来源）；`gui_settings.configure_all_tk_fonts(root)` 在 widget 构建完毕后遍历全部 tk 命名字体二次兜底
   - 详见 [utils/gui/fonts.py](../utils/gui/fonts.py) 和 [gui/shared/gui_settings.py](../games/endfield/gui/shared/gui_settings.py)
8. **类型安全 — 模块级导入**：如果类型被**静态方法**（`@staticmethod`）、**类方法**（`@classmethod`）或**类作用域**（如类型注解 `-> list[SomeType]`）引用，必须在**模块顶部**用 `from ... import SomeType` 显式导入。禁止将这些类型放在方法内部的「惰性导入」（`from ... import SomeType`）中，因为静态方法/类作用域不在执行期作用域链上，Pylance 会报「未定义」错误。
   - ✅ 正确：`from utils.gui.help_dialog import HelpSection`（顶部）→ `@staticmethod def build() -> list[HelpSection]:`
   - ❌ 错误：`def show(self): from utils.gui_help_dialog import HelpSection; ...` 然后 `@staticmethod` 使用 `HelpSection`
9. **Qt 枚举值 — 禁止字面量整数**：所有 Qt 枚举参数必须使用枚举成员，**禁止**使用裸整数或 `Literal` 类型传参。Pylance 的 Qt 绑定会严格检查枚举类型，字面量整数会报「无法分配」类型错误。
   - ✅ 正确：`scroll.setFrameShape(QFrame.Shape.NoFrame)`、`self.tabs.setTabPosition(QTabWidget.TabPosition.North)`
   - ❌ 错误：`scroll.setFrameShape(0)`、`setTabPosition(1)`
10. **惰性导入（lazy import）规则**：
    - ✅ 惰性导入只用于：运行时才确定的模块（如插件、可选依赖）、递归导入避免
    - ❌ 惰性导入不用于：类型定义、基类、`@staticmethod`/`@classmethod` 使用的符号
    - 惰性导入时，`from` 中只放该模块中该函数**执行时**才需要的符号（如从 `from utils.gui.help_dialog import HelpDialog` 而非 `... import HelpDialog, HelpSection`）

11. **导入规范 — 显式导入原则**：每个 Python 文件必须通过显式、可追溯的 import 路径被引用。此原则与 [`.trae/rules/project_rules.md`](../.trae/rules/project_rules.md) 中的「Python 模块导入规范」一致：

    - **包内模块使用相对导入**：`from . import _path_setup` ✅ / `import _path_setup` ❌
    - **包内交叉引用用相对导入**：`from .main import app` ✅ / `from main import app` ❌
    - **入口脚本（`__main__`）用绝对导入**：`run_packaged_main.py` 使用 `import main` ✅（因被 `python xxx.py` 直接运行，相对导入会失效）
    - **包目录必须有 `__init__.py`**：使目录成为标准 Python 包，支持相对导入。禁止将无 `__init__.py` 的目录作为导入目标（命名空间包在 PyInstaller 下会失败）
    - **交叉引用层次**：同一包内 `from . import xxx` → 同一父包子包间 `from ..xxx import yyy` → 跨顶级包 `from calc_framework.xxx import yyy`

12. **新增依赖许可检查**：每次向 `pyproject.toml` 或 `requirements.txt` 添加新的第三方库时，必须先确认其许可证并更新文档：

    - 从 PyPI 或官方仓库获取 SPDX 许可证标识
    - **禁止引入**（除非律师审阅）：
      - GPL-3.0-only / GPL-3.0-or-later（传染性过强）
      - SSPL（非开源，商业受限）
      - 无许可证或自定义许可证（权利不明）
    - **谨慎使用**：
      - AGPL-3.0：项目自身许可；可选依赖禁止引入 AGPL，须替换为宽松许可
      - LGPL：可接受（如 PySide6），须保留版权声明，动态链接
    - ✅ **安全新增**：MIT、Apache 2.0、BSD-2/3-Clause、ISC、PSF License、HPND
    - 更新 [`NOTICES.md`](../NOTICES.md) 软件依赖表
    - 更新 [`docs/数据来源与许可.md`](数据来源与许可.md) §十四
    - 特殊条款（如 YOLO 模型商用受限）须在文档中注明

13. **导入排序**：代码库按 `future → 标准库 → 第三方 → 框架 → 本地应用` 四组排序，组间空行分隔。每组内按字母顺序。详见 [`.trae/rules/project_rules.md`](../.trae/rules/project_rules.md)「Python 代码风格规范 §1」。

14. **`__all__` 声明**：每个 `__init__.py` 必须显式声明 `__all__` 列表确定公共 API 边界。空包须写 `__all__: list[str] = []`。禁止隐式导出。

15. **文档字符串（Google 风格，中文）**：

    | 范围 | 要求 |
    |------|------|
    | **必须写** | 公共 API（跨模块 import、`__all__` 导出）；FastAPI 路由与 Pydantic 模型；**长函数**（函数体不含 docstring 约 **≥ 40 行**，或分支/职责明显复杂） |
    | **可不写** | 模块内 `_` 前缀短 helper；≤3 行有效代码的 trivial wrapper；名称已自解释的私有小函数 |
    | **酌情** | 其余内部函数：逻辑清晰可不写；算法或非 obvious 边界建议写 |

    格式：Google 风格（`参数:` / `返回:` / `Raises:`）；简单公共函数可用单行。模块 docstring 在 `# SPDX-License-Identifier` 之后、第一个 import 之前。

16. **异常层级**：异常类以 `Error` 结尾，有文档字符串，基类 + 子类层次结构。特定构造参数用仅限关键字参数（`*` 后）。专用 `errors.py` 模块存放。

17. **Pydantic 模型命名（Web 后端）**：请求体 `<名词>Request`，响应 `<名词>Response`。路由装饰器用 `response_model=`。模型定义在路由模块顶部。

18. **HTTP 错误码语义（Web 后端）**：400=验证失败/无效输入，404=资源不存在，409=创建冲突，500=服务器内部错误。所有错误通过 `HTTPException(detail=str)` 返回。状态码不得误用。

19. **测试组织规范**：测试函数 `test_` 前缀 + `snake_case`，类内用 `TestXxx` 前缀。Fixture 分三级（包级 conftest → 目录级 conftest → 模块级）。慢测用 `@pytest.mark.slow`/`integration`/`real_data` 标记。
