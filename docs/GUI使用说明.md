# 终末地伤害计算器 — GUI 使用说明

> 本文档详细说明三个 GUI 的界面结构、按钮功能、文件位置。
> 领域术语见 [CONTEXT.md](../CONTEXT.md)；操作命令见 [操作指令集.md](操作指令集.md)。

---

## 一、启动方式

| 应用 | 命令 | 说明 |
|------|------|------|
| **伤害计算器** | `python games/endfield/main.py` | 选角色/武器 → 确认 → 看伤害乘区 |
| **数据设计器** | `python games/endfield/designer_main.py` | 公式反推 / 数据浏览 / 数据编辑 |
| **DAG 工具** | `python games/endfield/dag_main.py` | DAG JSON 生成与调试 |

打包后的 exe 路径同理（`终末地伤害计算器.exe` / `终末地设计器.exe`）。

## 二、伤害计算器 — 界面总览

窗口分两个页签：**计算页**（默认）和 **高级页**。

### 2.1 计算页

布局为五列（从左到右）：

| 列 | 名称 | 说明 |
|----|------|------|
| 第1列 | **角色选择** | 选择角色 → 星级 → 等级 → 潜能 → 信赖 → 技能等级 |
| 第2列 | **武器选择** | 选择武器 → 星级 → 等级 → 武器技能（普通/特殊） |
| 第3列 | **角色属性** | 确认后展示角色最终属性面板 |
| 第4列 | **武器属性** | 确认后展示武器最终属性面板 |
| 第5列 | **乘区数据** | 确认后展示 15 个伤害乘区明细 + 总伤面板 |

**顶部**：标题栏显示版本号。**底部**：状态栏显示当前操作提示。

#### 操作流程

1. **选角色**：下拉框选择 → 自动过滤可用武器
2. **选武器**：下拉框选择（武器列表按角色类型自动过滤）
3. **设置参数**：等级、潜能、信赖、技能等级等
4. **点击「确认选择」**：按钮位于第5列底部，也可在高级页点击
5. **查看结果**：角色/武器属性列 + 乘区数据 + 总伤面板自动刷新

> 切换角色或武器会自动触发重新计算。
> 修改等级/信赖/技能等级后按钮会显示「待更新」，需再次点击确认。

| **🤝 自愿捐赠** | 捐赠信息弹窗 |
| **📖 使用说明** | 打开本文档（即本文件） |
| **📂 搜索历史** | 浏览 `search_output/` 中的历史搜索记录 |

**计算模式**下拉框：

| 模式 | 说明 |
|------|------|
| 单段伤害计算 | 仅显示当前技能的单段伤害 |
| 乘区快照 | 显示全部 15 个乘区的详细数据 |
| 单技能遍历(快速预览) | 快速预览当前技能的结果 |
| 多技能遍历(快速预览) | 多技能段级加权预览 |

**更多设置（折叠/展开）**：

| 子项 | 说明 |
|------|------|
| **敌方参数面板** | 选择插件敌人 / 手动设置防御、抗性、失衡易伤等 |
| **导出配装 (.json)** | 将当前配存导出为 JSON 文件 |
| **导入配装 (.json)** | 从 JSON 文件导入配装 |
| **多方案对比** | 批量导入多个配装 JSON 进行横向对比 |
| **伤害仪表盘** | matplotlib 饼图/柱状图展示伤害分布 |
| **计算历史** | 查看最近 10 次计算结果 |
| **导出操作日志** | 导出用户操作日志（附 Bug 报告用） |
| **截图识装** | OCR 识别游戏截图中的装备 |

#### 中列 — 全量搜索

| 控件 | 说明 |
|------|------|
| **武器候选范围** | 当前武器 / 同类型同星级 / 同类型全部 |
| **装备范围** | 全部装备 / 仅套装装备 / 仅散件装备 |
| **固定配装（0-4件）** | 勾选部位 + 选择具体装备名称，未选部位遍历全部 |
| **最优搜索** | 搜索最优配装并导出到 `search_output/` |
| **全量遍历搜索** | 进行全量遍历搜索（弹窗展示结果） |
| **取消搜索** | 取消正在进行的搜索 |
| **并行线程** | 搜索使用的 CPU 线程数（默认逻辑核数-1） |
| **前列条数** | 保留的最优结果数量（3/5/10/20/50） |

搜索进度会显示在下方提示区域，包括预计组合数、搜索状态、预估时间。

---

#### 右列 — 多技能次数与异常

| 控件 | 说明 |
|------|------|
| **使用手动次数** | 勾选后启用段级次数手动输入 |
| **技能段数** | 各技能段（战技/连携技/终结技）的触发次数 |
| **额外加成微调** | 对指定段添加额外的乘区 buff（百分比加成） |
| **伤害口径** | 仅技能 / 仅异常 / 技能+异常 |
| **期望伤害模式** | 按暴击率取期望伤害（而非单次） |
| **装备条件暴击** | 计入装备的条件暴击率 |
| **额外暴击率%** | 手动添加的额外暴击率 |
| **额外暴伤%** | 手动添加的额外暴击伤害 |
| **物理异常** | 侵蚀/灼烧/冻伤/战栗各等级的触发次数矩阵 |
| **法术异常** | 侵蚀(法术)/灼烧(法术)各等级的触发次数矩阵 |
| **清空全部异常次数** | 一键重置所有异常次数为 0 |

## 三、数据设计器

启动命令：`python games/endfield/designer_main.py`

三个页签：

### 公式反推
粘贴 90 级/技能 9-12 级的属性数值，自动反推成长公式参数。

### 数据编辑
图形化新增/编辑/删除角色、武器、装备数据，保存后自动刷新缓存。

### 数据浏览
选择数据类型（角色/武器/装备），查看 JSON 列表。点击可查看详情。

启动命令：

|------|------|------|
| **根入口** | `python graph_editor_main.py` | 仓库根目录调用 |

### 4.1 界面总览

窗口分三栏布局：

```
┌─────────────────────────────────────────────────────────────┐
│ [新建] [打开] [保存] [导入包] [删除] [适配] [重置] [运算] [清除] │  ← 工具栏
├──────────┬──────────────────────────────────┬───────────────┤
│ 节点面板  │            画布                  │  属性面板      │
│          │   ┌─────┐                       │  节点属性      │
│  [输入]   │   │常量  │──→┌─────┐            │  类型: binary  │
│  [基础]   │   │(3.14)│   │一元  │           │  运算符: *     │
│  [输出]   │   └─────┘   │取整  │           │  预览: 260.0   │
│  [包]     │            └─────┘            │               │
│  + 导入包 │  ┌─────┐    ┌─────┐            │               │
│           │  │用户  │──→│输出  │            │               │
│           │  │输入  │   │标记  │            │               │
│           │  └─────┘    └─────┘            │               │
├──────────┴──────────────────────────────────┴───────────────┤
│ 状态: 就绪                                                 │
└─────────────────────────────────────────────────────────────┘
```

### 4.2 节点面板（左侧）

按分类展示所有可用节点类型。分类标签横向排列在顶部：**[输入] [基础] [输出] [包]**。

**拖拽创建节点**：从面板拖拽节点类型到画布上，松开鼠标即创建。

#### 基础节点类型

| 类型 | 颜色 | 输入 | 输出 | 说明 |
|------|------|------|------|------|
| **常量**（const） | 青色 | 0 | 1 | 固定数值输出。双击可设置值 |
| **变量引用**（var） | 蓝色 | 0 | 1 | 引用外部数据源变量。需配置变量路径（如 `character.基础攻击`） |
| **用户输入**（user_input） | 绿色 | 0 | 1 | 运行时用户可调节的参数。可设置默认值、最小值、最大值 |
| **一元运算**（unary） | 黄色 | 1 | 1 | 单输入运算：取整(floor/ceil)、取绝对值(abs)、开方(sqrt)、对数(ln/log10)、三角函数(sin/cos/tan/asin/acos/atan) |
| **二元运算**（binary） | 红色 | 2 | 1 | 双输入运算：加(+)、减(-)、乘(*)、除(/)、乘方(^)、取大(max)、取小(min)、取模(mod) |
| **条件分支**（condition） | 紫色 | 3 | 1 | 三输入：条件、真值、假值。条件为真时输出真值，否则输出假值 |
| **输出标记**（output） | 橙色 | 1 | 0 | 标记计算结果为重要输出。编译时自动回溯其输入源节点 |

#### 复合节点（composite）

从 JSON 或 ZIP 包导入的复合节点，将一整张子图封装成一个节点。

| 特征 | 说明 |
|------|------|
| **端口** | 由子图中的 `user_input` 和 `output` 节点自动推断 |
| **双击** | 打开子图编辑器，可修改内部计算逻辑 |
| **打包** | 多个复合节点可打包成 ZIP 文件分发 |

### 4.3 工具栏

| 按钮 | 快捷键 | 功能 |
|------|--------|------|
| **[新建]** | Ctrl+N | 清空画布，创建空白计算图 |
| **[打开]** | Ctrl+O | 打开 .json 计算图文件 |
| **[保存]** | Ctrl+S | 保存当前计算图为 .json 文件 |
| **[导入包]** | — | 导入计算包（.zip 包导入多个复合节点 / .json 导入单个复合节点） |
| **[删除]** | Delete | 删除选中的节点及关联连线 |
| **[适配]** | — | 自动缩放画布，使所有节点居中显示 |
| **[重置]** | — | 恢复画布缩放为 100% |
| **[运算]** | — | 编译整个计算图并求值，弹窗显示所有节点值和输出结果 |
| **[清除]** | — | 清空画布所有节点和连线 |

### 4.4 画布操作

| 操作 | 方式 |
|------|------|
| **选中节点** | 左键单击节点 |
| **移动节点** | 拖动节点（自动吸附到 40px 网格） |
| **创建连线** | 从节点的**输出端口**拖动到另一个节点的**输入端口** |
| **删除节点/连线** | 选中后按 Delete 键 |
| **平移画布** | 鼠标中键拖动 |
| **缩放画布** | 滚轮缩放 |
| **拖拽创建节点** | 从左侧节点面板拖拽到画布 |
| **双击复合节点** | 打开子图编辑器，编辑内部计算逻辑 |
| **适配所有节点** | 工具栏「适配」按钮 |

### 4.5 属性面板（右侧）

选中节点后在属性面板中编辑：

- **常量节点**：设置数值
- **变量引用节点**：设置变量路径
- **用户输入节点**：设置默认值、最小值、最大值、步长
- **一元运算节点**：选择运算类型（floor/ceil/abs/sqrt/ln/log10/sin/cos/tan/asin/acos/atan）
- **二元运算节点**：选择运算类型（+/-/*/÷/^/min/max/mod）
- **条件分支节点**：设置多个条件
- **输出标记节点**：无需配置

面板底部显示该节点的**实时预览值**（编译求值后的计算结果）。

### 4.6 导入计算包

**方式 1：工具栏** — 点击 **[导入包]** 按钮  
**方式 2：节点面板** — 切换到 **[包]** 选项卡 → 点击 **+ 导入包** 按钮

支持的文件格式：

| 格式 | 说明 |
|------|------|
| **.json** | 单个复合节点文件。导入后在「包」选项卡中显示 |
| **.zip** | 计算包，含多个 .json 文件。ZIP 的名称即为包名，包内每个文件对应一个复合节点 |

导入后自动切换到「包」选项卡，复合节点可从面板拖拽到画布使用。

**预置包**：`output/终末地乘区包.zip` — 终末地 15 个伤害乘区的完整计算包。

### 4.7 文件格式

导出文件为 `.json`，格式：

```json
{
  "schema_version": "calc-graph-v1",
  "name": "图名称",
  "description": "图描述",
  "nodes": [{"id": "n1", "type": "const", "op": "", "label": "常量", "config": {...}, "position": {"x": 0, "y": 0}}, ...],
  "edges": [{"from_node": "n1", "from_port": 0, "to_node": "n2", "to_port": 0}, ...],
  "layout": {"sections": [...]},
  "external_variables": {}
}
```

## 七、术语对照

| 界面显示 | 含义 |
|---------|------|
| 前列条数 | 搜索结果中保留的最优方案数量 |
| 最优搜索 | 搜索最优配装方案并自动导出 |
| 全量遍历 | 遍历所有武器+装备组合 |
| 额外加成微调 | 对特定技能段手动添加乘区 Buff |
| 加权总伤 | 各技能段伤害 × 触发次数 之和 |
| 期望伤害模式 | 按「暴击率 × 暴击伤害 + (1-暴击率) × 普通伤害」计算期望 |
| 物理异常 | 侵蚀/灼烧/冻伤/战栗 |
| 法术异常 | 侵蚀(法术)/灼烧(法术) |
