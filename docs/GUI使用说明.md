# 终末地伤害计算器 — GUI 使用说明

> 本文档详细说明三个 GUI 的界面结构、按钮功能、文件位置。
> 领域术语见 [CONTEXT.md](../CONTEXT.md)；操作命令见 [操作指令集.md](操作指令集.md)。

---

## 一、启动方式

| 应用 | 命令 | 说明 |
|------|------|------|
| **伤害计算器** | `python games/endfield/main.py` | 选角色/武器 → 确认 → 看伤害乘区 |
| **数据设计器** | `python games/endfield/designer_main.py` | 公式反推 / 数据浏览 / 数据编辑 |
| **DAG 工具** | `python games/endfield/dag_main.py` | DAG JSON 生成与调试 |

打包后的 exe 路径同理（`终末地伤害计算器.exe` / `终末地设计器.exe`）。

---

## 二、伤害计算器 — 界面总览

窗口分两个页签：**计算页**（默认）和 **高级页**。

### 2.1 计算页

布局为五列（从左到右）：

| 列 | 名称 | 说明 |
|----|------|------|
| 第1列 | **角色选择** | 选择角色 → 星级 → 等级 → 潜能 → 信赖 → 技能等级 |
| 第2列 | **武器选择** | 选择武器 → 星级 → 等级 → 武器技能（普通/特殊） |
| 第3列 | **角色属性** | 确认后展示角色最终属性面板 |
| 第4列 | **武器属性** | 确认后展示武器最终属性面板 |
| 第5列 | **乘区数据** | 确认后展示 15 个伤害乘区明细 + 总伤面板 |

**顶部**：标题栏显示版本号。**底部**：状态栏显示当前操作提示。

#### 操作流程

1. **选角色**：下拉框选择 → 自动过滤可用武器
2. **选武器**：下拉框选择（武器列表按角色类型自动过滤）
3. **设置参数**：等级、潜能、信赖、技能等级等
4. **点击「确认选择」**：按钮位于第5列底部，也可在高级页点击
5. **查看结果**：角色/武器属性列 + 乘区数据 + 总伤面板自动刷新

> 切换角色或武器会自动触发重新计算。
> 修改等级/信赖/技能等级后按钮会显示「待更新」，需再次点击确认。

---

### 2.2 高级页

点击「前往高级页」或顶部页签切换到高级页。布局为三列：

#### 左列 — 操作

| 按钮/控件 | 说明 |
|-----------|------|
| **返回计算页** | 切换回计算页 |
| **确认选择** | 同计算页的确认按钮 |
| **数据来源与许可** | 查看数据来源声明、许可信息 |
| **🤝 自愿捐赠** | 捐赠信息弹窗 |
| **📖 使用说明** | 打开本文档（即本文件） |
| **📂 搜索历史** | 浏览 `search_output/` 中的历史搜索记录 |

**计算模式**下拉框：

| 模式 | 说明 |
|------|------|
| 单段伤害计算 | 仅显示当前技能的单段伤害 |
| 乘区快照 | 显示全部 15 个乘区的详细数据 |
| 单技能遍历(快速预览) | 快速预览当前技能的结果 |
| 多技能遍历(快速预览) | 多技能段级加权预览 |

**更多设置（折叠/展开）**：

| 子项 | 说明 |
|------|------|
| **敌方参数面板** | 选择插件敌人 / 手动设置防御、抗性、失衡易伤等 |
| **导出配装 (.json)** | 将当前配存导出为 JSON 文件 |
| **导入配装 (.json)** | 从 JSON 文件导入配装 |
| **多方案对比** | 批量导入多个配装 JSON 进行横向对比 |
| **伤害仪表盘** | matplotlib 饼图/柱状图展示伤害分布 |
| **计算历史** | 查看最近 10 次计算结果 |
| **导出操作日志** | 导出用户操作日志（附 Bug 报告用） |
| **截图识装** | OCR 识别游戏截图中的装备 |

---

#### 中列 — 全量搜索

| 控件 | 说明 |
|------|------|
| **武器候选范围** | 当前武器 / 同类型同星级 / 同类型全部 |
| **装备范围** | 全部装备 / 仅套装装备 / 仅散件装备 |
| **固定配装（0-4件）** | 勾选部位 + 选择具体装备名称，未选部位遍历全部 |
| **最优搜索** | 搜索最优配装并导出到 `search_output/` |
| **全量遍历搜索** | 进行全量遍历搜索（弹窗展示结果） |
| **取消搜索** | 取消正在进行的搜索 |
| **并行线程** | 搜索使用的 CPU 线程数（默认逻辑核数-1） |
| **前列条数** | 保留的最优结果数量（3/5/10/20/50） |

搜索进度会显示在下方提示区域，包括预计组合数、搜索状态、预估时间。

---

#### 右列 — 多技能次数与异常

| 控件 | 说明 |
|------|------|
| **使用手动次数** | 勾选后启用段级次数手动输入 |
| **技能段数** | 各技能段（战技/连携技/终结技）的触发次数 |
| **额外加成微调** | 对指定段添加额外的乘区 buff（百分比加成） |
| **伤害口径** | 仅技能 / 仅异常 / 技能+异常 |
| **期望伤害模式** | 按暴击率取期望伤害（而非单次） |
| **装备条件暴击** | 计入装备的条件暴击率 |
| **额外暴击率%** | 手动添加的额外暴击率 |
| **额外暴伤%** | 手动添加的额外暴击伤害 |
| **物理异常** | 侵蚀/灼烧/冻伤/战栗各等级的触发次数矩阵 |
| **法术异常** | 侵蚀(法术)/灼烧(法术)各等级的触发次数矩阵 |
| **清空全部异常次数** | 一键重置所有异常次数为 0 |

## 三、数据设计器

启动命令：`python games/endfield/designer_main.py`

三个页签：

### 公式反推
粘贴 90 级/技能 9-12 级的属性数值，自动反推成长公式参数。

### 数据编辑
图形化新增/编辑/删除角色、武器、装备数据，保存后自动刷新缓存。

### 数据浏览
选择数据类型（角色/武器/装备），查看 JSON 列表。点击可查看详情。

## 五、文件位置说明

### 游戏数据文件

| 数据 | 路径（相对于仓库根） |
|------|---------------------|
| 角色数据 | `games/endfield/character_weapon_equipment/character_data/characters.json` |
| 武器数据 | `games/endfield/character_weapon_equipment/weapon_data/weapons.json` |
| 装备数据 | `games/endfield/character_weapon_equipment/equipment_data/equipments.json` |

> 这些文件由 BWIKI 工具链同步或手动编辑，修改后程序自动刷新缓存。

### 搜索输出

| 内容 | 路径 |
|------|------|
| 搜索结果数据库 | `search_output/<运行时间戳>/search_runs.db` |
| 导出 CSV/JSON | 同上目录 |

> 所有搜索结果保存在 `search_output/` 目录下，可通过高级页的「搜索历史」按钮浏览。

### 插件数据

| 内容 | 路径 |
|------|------|
| 插件敌人 | `games/endfield/plugins/enemies/*.yaml` |

## 六、术语对照

| 界面显示 | 含义 |
|---------|------|
| 前列条数 | 搜索结果中保留的最优方案数量 |
| 最优搜索 | 搜索最优配装方案并自动导出 |
| 全量遍历 | 遍历所有武器+装备组合 |
| 额外加成微调 | 对特定技能段手动添加乘区 Buff |
| 加权总伤 | 各技能段伤害 × 触发次数 之和 |
| 期望伤害模式 | 按「暴击率 × 暴击伤害 + (1-暴击率) × 普通伤害」计算期望 |
| 物理异常 | 侵蚀/灼烧/冻伤/战栗 |
| 法术异常 | 侵蚀(法术)/灼烧(法术) |
