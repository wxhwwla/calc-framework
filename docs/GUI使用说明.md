## 1. 启动与窗口概览

### 启动方式

```bash
cd endfield_damage_calculator   # [包]
python main.py
```

首次使用前请确保已安装依赖：

```bash
pip install -e ".[dev]"
```

### 窗口结构

主窗口为 **双页签设计**，默认 1280×720，最小 1024×600：

| 页签 | 用途 |
|------|------|
| **计算页** | 角色/武器选择、属性展示、乘区计算（日常操作主界面） |
| **高级页** | 全量搜索、多技能加权、异常矩阵、工具与分享 |

窗口标题显示版本号（`_EXE_VERSION`）。

### 启动页策略

应用会记住上次关闭时的页签。可在 `ui_preferences.json` 中修改 `startup_page_mode`：

- `"always_main"`（默认）：总是启动到计算页
- `"remember_last"`：恢复上次关闭时的页签

## 2. 计算页（主视图）

计算页是日常操作的主界面，包含四个区域：

```
┌─────────────────────────────────────────────────────────────┐
│  角色选择面板  │  武器选择面板  │  属性列  │  乘区展示      │
│  ┌──────────┐  │  ┌──────────┐  │  ┌────┐  │  ┌──────────┐ │
│  │ 类型     │  │  │ 类型     │  │  │角色│  │  │ 计算模式 │ │
│  │ 星级     │  │  │ 星级     │  │  │属性│  │  │ 乘区A    │ │
│  │ 名称     │  │  │ 名称     │  │  │    │  │  │ 乘区B    │ │
│  │ 等级     │  │  │ 等级     │  │  │武器│  │  │ 乘区C    │ │
│  │ 技能等级 │  │  │ 技能等级 │  │  │属性│  │  │ ...      │ │
│  │ 信赖     │  │  │ 潜能/层数│  │  │    │  │  │          │ │
│  │ 高级参数 │  │  │ 高级参数 │  │  │    │  │  │          │ │
│  └──────────┘  │  └──────────┘  │  └────┘  │  └──────────┘ │
```

### 2.1 角色选择面板

左起第一个面板，四级联动筛选：

| 控件 | 说明 |
|------|------|
| **类型下拉** | 筛选角色类型（近卫、术师、辅助等） |
| **星级下拉** | 按星级筛选（3–6 星） |
| **名称下拉** | 选择具体角色。变更时会自动过滤武器面板（只显示该角色可用的武器类型） |
| **等级滑块** | 1–90 级，拖拽实时更新属性列 |
| **技能等级** | 战技（1–12 级）、连携技（1–9 级）、终结技（1–9 级） |
| **信赖等级** | 0–200，影响能力乘区 |
| **高级参数** | 折叠面板，包含能力值微调（见下方） |

**高级参数（折叠）**：

| 参数 | 说明 |
|------|------|
| 主能力值修正 | 手动覆盖角色主能力值（用于临时 Buff 模拟） |
| 副能力值修正 | 手动覆盖角色副能力值 |
| 基础攻击力修正 | 手动覆盖基础攻击力 |

### 2.2 武器选择面板

左起第二个面板，与角色面板对称布局：

| 控件 | 说明 |
|------|------|
| **类型下拉** | 武器类型（自动按角色过滤） |
| **星级下拉** | 按星级筛选 |
| **名称下拉** | 选择具体武器 |
| **等级滑块** | 1–90 级 |
| **普通技能等级** | 各槽位 1–9 级（对应潜能 0–5 档） |
| **特殊技能等级与层数** | 特殊技能等级 + 最大层数 |
| **高级参数** | 折叠面板，包含武器词条微调 |

### 2.3 属性列展示区

中间两列，确认选择后展示详细属性：

**角色属性列**：

| 项目 | 说明 |
|------|------|
| 四维属性 | 力量、敏捷、智识、意志的当前等级值 |
| 基础攻击力 | 当前等级的基础攻击力 |
| 战技倍率 | 当前等级的战技倍率 |
| 连携技倍率 | 当前等级的连携技倍率 |
| 终结技倍率 | 当前等级的终结技倍率 |

**武器属性列**：

| 项目 | 说明 |
|------|------|
| 基础攻击力 | 当前等级的武器基础攻击力 |
| 普通技能词条 | 各词条当前等级数值（如 `攻击力+23.4%`） |
| 特殊技能词条 | 各词条当前等级数值与层数效果（如 `法术伤害+12.8%/层` × 2） |

数值规则：
- `附加攻击力+`、四维+、主/副能力+ 等为**固定整数**
- `攻击力+`、`*伤害+`、`*率+`、充能效率 带 `%`

### 2.4 乘区展示区（ComputeSheet）

最右侧列（固定宽 340px），展示确认计算结果：

**计算模式**（可在高级页或计算页切换）：

| 模式 | 说明 |
|------|------|
| **乘区快照** | 显示 15 个乘区链的当前值（能力乘区、攻击力加成、暴击伤害、防御减伤等） |
| **单段伤害** | 显示单次技能的最终伤害值及各乘区明细 |

**乘区链（15 乘区）**：

| 序号 | 乘区 | 说明 |
|------|------|------|
| 1 | 能力乘区 | 主能力×0.005 + 副能力×0.002 |
| 2 | 能力值加成 | 信赖 + 武器词条能力值+ |
| 3 | 武器攻击力 | 武器基础攻击力 |
| 4 | 攻击力加成 | 攻击力+ 词条总和 |
| 5 | 暴击伤害 | 期望暴击倍率 |
| 6 | 伤害加成 | 全伤害+ / 物理伤害+ 等 |
| 7 | 防御减伤 | 100 / (100 + 防御×系数) |
| 8 | 抗性减伤 | 敌方抗性减免 |
| 9–15 | 其他乘区 | 特殊减伤、破韧补正、易伤增伤等 |

**确认按钮**：乘区列顶部有「确认选择」按钮，点击后刷新全部乘区数据。

## 3. 高级页（控制栏）

高级页为三列布局，集中管理搜索、加权、异常与工具。

### 3.1 操作列

左列，包含常用操作按钮：

| 按钮 | 说明 |
|------|------|
| **返回计算页** | 切换到计算页主视图 |
| **确认选择** | 刷新全部乘区/属性列（与计算页确认等效） |
| **数据来源与许可** | 打开许可信息对话框 |
| **自愿捐赠** | 显示捐赠信息 |

**计算模式**下拉：切换乘区快照 / 单段伤害模式。

**工具与分享**（「更多设置」折叠内）：

| 功能 | 说明 |
|------|------|
| **导出配装 (.json)** | 将当前配装导出为预设 JSON 文件 |
| **导入配装 (.json)** | 加载预设 JSON 文件，恢复配装状态 |
| **多方案对比** | 对比多套配装的乘区与伤害差异 |
| **伤害仪表盘** | matplotlib 图表展示各乘区贡献占比 |
| **计算历史** | 查看历史确认记录 |
| **导出操作日志** | 将本次会话的操作日志导出为文本文件 |

**插件敌人**下拉：选择预设敌人模板，自动应用对应的防御/抗性值。

### 3.2 全量搜索列

中列，配置与执行全量装备搜索：

| 控件 | 说明 |
|------|------|
| **武器候选范围** | 指定武器搜索范围：全部 / 同类型同星级 / 同类型全部 |
| **装备范围** | 指定装备池：全部装备 / 仅套装 / 仅散件 |
| **固定配装** | 四槽下拉（护甲、护手、配件A、配件B）。选具体装备则固定该槽，选「（不固定）」则在装备范围遍历 |
| **并行线程** | 搜索并发数：自动（逻辑核数-1）或手动指定 |
| **Top 条数** | 输出排名 Top N（3/5/10/20/50） |
| **MVP 搜索** | 快速搜索并弹出结果窗口 |
| **全量遍历搜索** | 完整搜索并导出到 `search_output/` |
| **取消搜索** | 中断正在进行的搜索 |
| **搜索预估** | 自动显示预计组合数与估算耗时 |

**搜索流程说明**：

1. 选择武器和装备范围
2. 可选：固定 0–4 件装备（减少组合数）
3. 点击「MVP 搜索」或「全量遍历搜索」
4. 搜索过程中可随时取消
5. 搜索完成后自动弹出结果或导出

### 3.3 多技能次数列

右列，配置技能加权与异常伤害：

| 控件 | 说明 |
|------|------|
| **使用手动次数** | 开启后按段级加权总伤排名（关闭则按当前技能单段伤害） |
| **技能段数** | 各技能段的释放次数输入（如战技×3、连携技×1） |
| **场外 Buff 微调** | 打开外部 Buff 编辑窗口 |
| **伤害口径** | 仅技能 / 仅异常 / 技能+异常 |
| **期望伤害模式** | 勾选后暴击按期望值计算（暴击率×暴伤） |
| **装备条件暴击** | 勾选后包括装备提供的条件暴击率 |
| **额外暴击率%** | 手动输入的额外暴击率（如食物 Buff） |
| **额外暴伤%** | 手动输入的额外暴伤（如食物 Buff） |

**技能段数说明**：

开启「使用手动次数」后，搜索按 **Σ(各技能单段伤害 × 次数)** 加权排名。例如：

| 技能段 | 单段伤害 | 次数 | 加权伤害 |
|--------|---------|------|---------|
| 战技 | 5000 | 3 | 15000 |
| 连携技 | 8000 | 1 | 8000 |
| **总伤** | | | **23000** |

## 4. 确认计算流程

### 手动确认

1. 在计算页选择角色和武器
2. 调整等级、技能等级等参数
3. 点击「确认选择」按钮
4. 属性列和乘区列刷新

### 自动确认

- 首次启动后自动执行一次确认
- 切换角色/武器时的参数变更会自动触发确认

### 待确认提示

当配装参数变更（如调整等级、切换计算模式）而尚未确认时：

- 计算页「确认选择」按钮变为紫色「确认选择（待更新）」
- 高级页状态栏显示「待确认」
- 点击确认恢复蓝色

### 确认后效果

- 角色/武器属性列刷新为当前等级数值
- 乘区列重新计算并展示 15 乘区链
- 计算历史记录当前快照
- 搜索预估刷新

## 5. 全量搜索详解

### 搜索范围

全量搜索枚举三种维度：

| 维度 | 枚举内容 | 组合影响 |
|------|---------|---------|
| 武器 | 按「武器候选范围」筛选的武器列表 | 乘法增长 |
| 装备护甲 | 护甲部位的装备列表（或固定的一件） | 乘法增长 |
| 装备护手 | 护手部位的装备列表（或固定的一件） | 乘法增长 |
| 配件 A/B | 配件部位的装备列表（或固定的一件） | 乘法增长 |

全部组合数 = `武器数 × 护甲数 × 护手数 × 配件A数 × 配件B数`。

### 评分方式

| 模式 | 评分依据 |
|------|---------|
| 关闭「使用手动次数」 | 左侧当前技能单段伤害 |
| 开启「使用手动次数」 | Σ(各技能段单段伤害 × 次数) |

### 输出结果

- **MVP 搜索**：弹窗显示 TopN 结果列表
- **全量遍历搜索**：导出到 `search_output/` 目录
  - 文件命名：`full_search_*_yyyy-mm-dd_HH-MM-SS.txt`
  - 内容：TopN 配装详情（装备名称、属性、伤害值等）

### 性能建议

| 组合数范围 | 建议操作 |
|-----------|---------|
| < 1 万 | 全量遍历，几乎立即完成 |
| 1–10 万 | 全量遍历，几秒至几十秒 |
| 10–100 万 | 全量遍历，1–5 分钟 |
| > 100 万 | 建议使用固定配装减少组合数，或使用 MVP 搜索 |

## 6. 工具与分享

### 多方案对比

![多方案对比示意]

保存多套配装配置，并排对比各乘区数值和最终伤害：

1. 在计算页配置好第一套配装
2. 进入高级页 → 更多设置 → 「多方案对比」
3. 点「添加当前配装」保存第一套
4. 切换角色/武器，点「添加当前配装」保存第二套
5. 可添加多套进行对比
6. 查看对比表格：每行一个乘区，每列一套配装

### 伤害仪表盘

使用 matplotlib 生成伤害乘区贡献图：

- 饼图：各乘区对最终伤害的贡献占比
- 柱状图：各乘区数值对比
- 仪表盘作为独立窗口弹出，可缩放保存

### 计算历史

- 每次确认计算后自动记录快照
- 格式：`角色 + 武器 + 等级 + 技能等级 → 各乘区数值`
- 可回溯历史状态
- 关闭窗口后清空（不持久化）

### 导出操作日志

- 记录本次会话的所有操作（切换角色、调整等级、确认等）
- 导出为 `.txt` 文件
- 用于排错或复盘

## 7. 预设系统

### 导出预设

当前配装状态导出为 JSON 文件：

```json
{
  "schema": "endfield_loadout_preset_v2",
  "char_name": "秋栗",
  "weapon_name": "逐鳞3.0",
  "char_level": 90,
  "weapon_level": 90,
  "trust_level": 0,
  "skill_1_level": 7,
  "skill_2_level": 4,
  "skill_3_level": 4,
  "weapon_normal_levels": [9, 8, 1],
  "weapon_special_states": [
    {"level": 7, "stack": 2}
  ],
  "multi_skill_counts": {"战技:1": 3, "连携技:1": 1}
}
```

### 导入预设

- 支持 v2（`endfield_loadout_preset_v2`）和 v1（旧格式）
- v1 的 `ws_*` 字段自动归一化
- 导入后自动恢复角色、武器、等级、技能等级等状态

### 配装文件管理

- 导出位置：系统对话框指定
- 导入位置：系统对话框选择
- 建议命名：`{角色}_{武器}_预设.json`

## 8. 异常矩阵系统

### 物理异常

| 类型 | 等级范围 | 说明 |
|------|---------|------|
| 侵蚀 | L1–L5 | 物理持续伤害 |
| 灼烧 | L1–L5 | 物理灼烧伤害 |
| 冻伤 | L1–L5 | 物理冻结相关 |
| 战栗 | L1–L5 | 物理恐惧相关 |

### 法术异常

| 类型 | 等级范围 | 说明 |
|------|---------|------|
| 侵蚀(法术) | L1–L4 | 法术持续伤害 |
| 灼烧(法术) | L1–L4 | 法术灼烧伤害 |

### 操作方式

1. 在高级页 → 多技能次数列
2. 找到物理异常或法术异常区域
3. 按类型 × 等级矩阵填入期望触发次数
4. 异常伤害会按口径设置（仅技能 / 仅异常 / 技能+异常）计入总伤

### 清空异常次数

点击「清空全部异常次数」按钮重置所有异常输入为 0。

## 9. 外部 Buff 微调

用于模拟战斗外 Buff（食物、药品、天赋等）：

| 参数 | 说明 |
|------|------|
| 攻击力 +% | 额外攻击力百分比加成 |
| 攻击力 + | 额外固定攻击力 |
| 暴击率 +% | 额外暴击率 |
| 暴伤 +% | 额外暴击伤害 |
| 全伤害 +% | 额外全伤害加成 |
| 能力值 + | 额外主/副能力值 |

**注意**：外部 Buff 与额外暴击率/暴伤（在面板上）是分开的。面板上的额外暴击率/暴伤主要覆盖食物类全局加成，外部 Buff 微调窗口用于更精细的场景模拟。

## 10. 数据来源与许可

- 软件许可（AGPL-3.0 / 商业许可）
- 数据许可说明
- BWIKI 数据来源

## 11. 常见问题

### Q: 启动报错「缺少依赖」

```bash
cd endfield_damage_calculator   # [包]
pip install -e ".[dev]"
```

### Q: 属性列不显示数据

确认已点击「确认选择」。首次启动会自动确认一次，但如果切换了角色/武器，需要再次确认。

### Q: 搜索耗时太长

- 使用固定配装减少组合数
- 缩小武器候选范围
- 增加并行线程数
- 使用 MVP 搜索代替全量遍历

### Q: 搜索结果为空

可能原因：

1. 当前角色/武器未选择
2. 装备 JSON 数据为空
3. 搜索范围过小导致无有效组合

### Q: 导入预设后部分参数不对

确认预设文件是 v2 格式。v1 格式会自动转换但可能丢失部分字段（如多技能次数）。

### Q: 如何添加新角色/武器数据

参考 [README.md](../endfield_damage_calculator/README.md) 中的开发指南：

```bash
python character_weapon_equipment/character_data/add_character.py
python character_weapon_equipment/weapon_data/add_weapon.py
```

### Q: 伤害仪表盘不显示中文

确保系统已安装中文字体（如 Microsoft YaHei）。仪表盘会自动使用系统默认 UI 字体显示中文。
