# 用户计算器创建手册

> **面向对象**：游戏玩家、数值爱好者、任何想做游戏伤害计算器的人
> **不需要**：编程经验、命令行知识、JSON 知识（有更好，但不是必须）

---

## 快速开始

你想为一个游戏做伤害计算器？跟着这三步走：

```
① 选模板 → ② 提供数据 → ③ AI 生成 → 完成 🎉
```

整个过程中 AI 会一步步引导你，你只需要：
- 回答 AI 的问题（你的游戏公式是什么）
- 提供数据（Wiki 链接 / 数据文件 / 口头描述）
- 确认 AI 生成的结果对不对

---

## 一、你需要准备什么

### 最少需要

只要你能回答 AI 这几个问题，就能生成一个可用的计算器：

1. **游戏叫什么？**（用于命名）
2. **最终伤害怎么算？** 比如"攻击力×技能倍率减防御力"之类的公式
3. **角色有哪些属性？** 比如攻击力、防御力、暴击率、暴击伤害...

### 更多数据 = 更完整的计算器

| 你有这个 | AI 能帮你做 |
|----------|------------|
| 公式描述（口头也行） | ✅ 生成基础计算器 |
| + 角色/武器数值表 | ✅ 加上角色武器选择面板 |
| + Wiki 链接 | ✅ 自动提取数据，更准确 |
| + 截图/文档 | ✅ AI 帮你从图片里提取数据 |

---

## 二、三种数据来源，选适合你的

根据你的情况，选择一种方式开始：

---

### 场景 A：有 Wiki 链接（推荐，最省力）

如果你玩的游戏有 Wiki（BWIKI、Fandom、灰机Wiki 等），这是最快的路径。

**流程**：

```
你给 AI 一个 Wiki 链接
  → AI 尝试用爬虫抓取数据
  → AI 整理出角色列表、武器列表、属性表
  → 你检查一下，告诉 AI 哪些有用、哪些不需要
  → AI 生成计算器
```

**你的任务**：
1. 找到游戏的 Wiki 主页
2. 把链接发给 AI
3. 确认 AI 提取的数据对不对

**注意**：如果爬虫抓不到（比如 Wiki 有反爬机制），AI 会告诉你，然后进入场景 C。

---

### 场景 B：有数据文件（Excel/JSON/CSV）

如果你已经有整理好的游戏数据（比如从游戏解包、社区表格、自己整理的），可以直接给 AI。

**流程**：

```
你上传数据文件
  → AI 解析文件内容
  → AI 展示"我读到了这些属性和数值，对吗？"
  → 你确认或修正
  → AI 生成计算器
```

**支持的文件格式**：

| 格式 | 说明 |
|------|------|
| JSON | 最佳，结构最清晰 |
| CSV / Excel (.xlsx) | 可以，AI 会尝试解析 |
| 纯文本 / Markdown 表格 | 可以，AI 会从文字中提取 |

**数据文件大概长什么样？**

最简单的格式，一个角色列表 JSON 文件：

```json
[
  { "name": "角色A", "ATK": 100, "DEF": 50, "HP": 1000 },
  { "name": "角色B", "ATK": 120, "DEF": 40, "HP": 800 }
]
```

或者 Excel 表格，只要列名清晰就行。

---

### 场景 C：什么都没有（纯手动输入）

如果游戏没有 Wiki，你也没有现成的数据文件，没关系。AI 会一步步问你。

**流程**：

```
AI 问："角色有哪些属性？"
你答："攻击力、防御力、暴击率"
AI 问："伤害公式是什么？"
你答："攻击力 × 技能倍率 - 防御力 × 0.5"
AI 问："有哪些角色？"
你答："角色A：攻击100，防御50...；角色B：攻击120，防御40..."
...（AI 逐个问，你逐个答）
→ AI 生成计算器
```

**你的任务**：回答 AI 的问题就行。就像在跟一个懂行的朋友聊天。

**如果数据太多不想一个一个说**：你还可以直接给 AI 贴一段整理好的数据：

```
角色名, 攻击力, 防御力, 生命值
角色A, 100, 50, 1000
角色B, 120, 40, 800
角色C, 80, 60, 1200
```

AI 能读懂这种表格格式。

## 三、完整示例

### 例1：有 Wiki 的情况

> **你**：我想做《明日方舟》的伤害计算器，这是 Wiki 链接 https://wiki.biligame.com/arknights/
>
> **AI**：好的！我用爬虫抓取 Wiki 数据。抓到了以下内容：
> - 干员：230+ 个
> - 属性：攻击、防御、生命、法抗、部署费用...
> - 伤害公式线索：（见 Wiki 页面）
>
> 请确认：这些数据对吗？需要我排除哪些类型？

> **你**：对，都抓到了。开始做吧。
>
> **AI 开始生成计算器...**

### 例2：没有 Wiki 也没有数据文件

> **你**：我想做《某款小众手游》的伤害计算器，没有 Wiki。
>
> **AI**：没问题，我来问你几个问题。
>
> 先说说伤害公式？比如"最终伤害 = 攻击力 × 技能倍率 - 防御力 × 0.5"这种。
>
> **你**：最终伤害 = 攻击力 × (1 + 伤害加成%) × 技能倍率 - 防御力
>
> **AI**：明白了。那角色有哪些属性？
>
> **你**：攻击力、防御力、生命值、暴击率、暴击伤害
>
> **AI**：好的。现在给我几个角色数据？你可以一个一个说，也可以直接贴表格。
>
> **你**：
> ```
> 剑士, 100, 50, 1000, 0.05, 0.5
> 法师, 80, 30, 800, 0.1, 0.8
> 坦克, 60, 100, 2000, 0.03, 0.3
> ```
>
> **AI**：我猜这些列依次是：攻击力、防御力、生命值、暴击率、暴击伤害，对吗？
>
> **你**：对。
>
> **AI 开始生成计算器...**

## 四、AI 生成完毕后

AI 会生成一组文件，这些就是你的计算器。你有两种方式使用它：

### 方式 1：Web 版（浏览器打开就用）

在 Web 页面的"适配器管理"中，你会看到你刚创建的计算器。
点击即可使用，无需安装任何东西。

### 方式 2：桌面版（下载 exe）

如果你是高级用户，可以把生成的文件放到框架目录下：
`framework/adapters/{你的游戏}/`

然后运行桌面计算器就能看到它。

### 方式 3：分享给其他人

你的计算器可以打包成一个 `.calcpack` 文件，分享给其他人。
别人在 Web 市场的"导入"功能上传即可使用。

## 五、常见问题

### Q：AI 生成的公式不对怎么办？

直接把正确的公式告诉 AI，让它修改。例如："暴击倍率应该是 1 + 暴击伤害，不是直接乘暴击伤害。"

### Q：AI 提取的 Wiki 数据少了些内容？

告诉 AI 少了什么，提供缺失内容的页面链接或截图。

### Q：我中途想加一个新属性/新公式？

告诉 AI 就行："再加一个穿透属性，计算公式是..."

### Q：我做了一半，第二天想继续？

保存好 AI 给你的对话，下次继续。目前还没有"保存进度"的功能。

### Q：我完全不懂这些，但想试试？

直接告诉 AI"我想做 XX 游戏的伤害计算器，但我什么都不懂"。
AI 会从最基础的问题开始问你，你只要回答知道的部分就行。
不知道的部分 AI 会基于同类游戏做合理猜测。

## 六、技术概览（给好奇的用户）

你不必理解这些，但如果你想知道 AI 到底生成了什么：

```
framework/adapters/你的游戏/
├── meta.json          ← 计算器的"身份证"
├── 你的游戏.dag.json  ← 公式计算图（最重要的文件）
├── attr_schema.json   ← 属性清单
├── functions.py       ← 自定义公式（如果有特殊计算）
└── ui/layout.json     ← 界面布局
```

所有文件都是标准格式，AI 生成后你也可以手动修改。
