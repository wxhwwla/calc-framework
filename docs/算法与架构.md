## 项目概述

本项目是一个用于计算《明日方舟：终末地》游戏中角色和武器属性成长的计算器工具。它提供了从属性数据反推成长公式参数的功能，以及根据成长参数生成完整属性曲线的能力。

## 核心功能模块

### 1. 计算引擎 (calculation/)

#### 1.1 公式计算 (formula.py)

**主要函数：**

| 函数名 | 功能描述 | 参数 | 返回值 |
|--------|----------|------|--------|
| `calculate_growth_curve` | 计算属性成长曲线 | base, growth, divisor, offset, max_level | List[float] (90个值) |
| `calculate_skill_curve` | 计算技能倍率曲线 | base, growth, divisor, offset, special_values | List[float] (12个值) |
| `calculate_bonus_attribute` | 计算附加属性曲线 | base, growth, divisor, offset, special, max_level | List[float] |

**公式说明：**
```
基础公式: round(base + floor((growth * (lv - 1) + offset) / divisor), 1)
```

#### 5.2 核心模块职责

| 模块 | 职责 | 核心类/函数 |
|------|------|-------------|
| `data/equipment_catalog.py` | 装备范围过滤 → 三部位 catalog | `get_equipment_catalog()` |
| `equipment_affix.py` | `属性词条` / 套装效果 → `DamageEffect` 与平铺四维 | `aggregate_loadout_modifiers()` |
| `equipment_prune.py` | 按主/副能力与技能类型**排序**（不减少组合总数） | `sort_equipment_catalog_by_priority()` |
| `loadout_slot_search.py` | `FixedLoadoutSelection`：固定件 + 未固定格遍历 | `iter_loadout_combinations_for_selection()` |
| `multi_skill_search_eval.py` | 手动次数 + 技能等级 → 场景与 `run_signature` token | `build_run_signature()` |
| `loadout_optimizer.py` | 构建搜索计划、单技能任务评估 | `build_optimizer_search_plan()`, `evaluate_task()` |
| `multi_skill_optimizer.py` | 多技能加权任务评估 | `evaluate_multi_skill_task()` |
| `search_session.py` | 搜索会话管理、续跑控制 | `run_search_session()` |
| `search_persistence.py` | SQLite 进度持久化、续跑恢复 | `execute_search_with_resume()` |
| `top_n_tracker.py` | Top-N 结果维护 | `TopNTracker` |

#### 5.3 搜索计划构建流程

`build_optimizer_search_plan()` 执行以下步骤：

1. **候选过滤**：根据 `candidate_weapon_names` 和 `candidate_equipment_names` 过滤武器和装备
2. **无益剪枝**：移除无效果、无属性词条的武器和装备（`prune_non_beneficial`）
3. **优先级排序**：按主/副属性和技能类型排序装备（`sort_equipment_by_priority`）
4. **固定配装解析**：解析 `FixedLoadoutSelection` 或 `varying_slot_count`
5. **组合计数**：计算总组合数（武器数 × 配装组合数）

#### 5.4 任务评估流程

`evaluate_task()` / `evaluate_multi_skill_task()` 执行以下步骤：

1. **构建配装**：`build_four_slot_loadout()` 将 JSON 数据转为运行时结构
2. **聚合修饰器**：`aggregate_loadout_modifiers()` 提取词条效果、平铺四维、攻击力%
3. **计算最终攻击**：`calculate_final_attack_with_details()` 含装备加成的攻击力
4. **伤害计算**：`calculate_single_hit_damage()` 执行 15 乘区链计算
5. **多技能加权**（仅多技能模式）：`Σ(单次伤害 × 释放次数)`

#### 5.5 续跑机制

搜索支持断点续跑，核心机制：

- **run_signature**：基于配置、数据版本、代码版本生成的唯一标识
- **SQLite 持久化**：`search_output/search_runs.db` 存储进度和中间结果
- **续跑条件**：相同 `run_signature` + 存在未完成的数据库 → 继续搜索
- **结果合并**：续跑完成后合并多次搜索的 Top-N 结果

**注意**：改固定配装、多技能次数、剪枝或词条逻辑后应新建 run；勿用旧 `search_runs.db` 的 `total_combinations` 对比进度。

#### 5.6 并行搜索策略

`run_enumerated_optimizer_parallel()` 采用以下策略：

- **任务分片**：按武器分组，每组分配独立进程
- **共享状态**：通过 `TopNTracker` 汇总各进程结果
- **进度追踪**：实时更新搜索进度和预估剩余时间
- **异常处理**：单个任务失败不影响整体搜索

### 6. 命令行工具 (scripts/)

#### 6.1 反向计算 CLI (inverse_cli.py)

**功能：** 交互式公式参数计算器

**使用方法：**
```bash
cd calc-framework
python scripts/inverse_cli.py
```

**支持的数据格式：**
- 属性数据：90或94个数值（等级1-90）
- 技能倍率：9或12个数值（等级1-9或1-12）

使用 `github_upload_module.py` / `github_download_module.py`，**默认 SSH**。勿将 Token 写入 `git remote`。

**版本与提交说明（必读）**：见 `games/endfield/please_read_me.py` 内 `UPLOAD_WORKFLOW`（`python games/endfield/please_read_me.py` 可打印）。

| 命令 | 作用 |
|------|------|
| `python github_upload_module.py` | 有业务改动时默认 patch +1，交互可选 minor；已配置签名时 commit 可显示 Verified |
| `python github_upload_module.py --minor` | 第二位 +1（新武器 JSON、新乘区等） |
| `python github_upload_module.py --no-bump` | 推送但不改 `_VERSION` |
| `python github_download_module.py` | **危险**：对齐 `origin/main`；须输入 **`覆盖本地`** 确认 |

流程摘要：自动生成底部 `UPLOAD_SUMMARY` → bump `_VERSION`（可选）→ 单 commit（可选 GPG/SSH 签名）→ push 成功则删除总结块；`_EXE_VERSION` 仅打包前手改。

下载脚本会 `reset --hard` 且 `git clean -fd`，未提交与未跟踪文件均可能丢失。详见 [`docs/操作指令集.md`](docs/操作指令集.md)。

## 常见问题

### Q1: 输入数据后提示"数据长度错误"

**原因：** 属性数据需要90或94个值，技能数据需要9或12个值

**解决：** 检查输入的数据数量是否正确

### Q2: 反推结果与预期不符

**原因：** 数据格式不正确或存在特殊值

**解决：**
- 确保数据为等级1到等级90（或9/12）的顺序
- 检查是否有重复数据需要处理
- 使用 `remove_duplicates` 函数处理94个数据的情况

### Q3: 导入模块失败

**原因：** Python路径未正确配置

**解决：**
```bash
cd calc-framework
python -c "import sys; sys.path.insert(0, '.'); from calculation.formula import calculate_growth_curve"
```
