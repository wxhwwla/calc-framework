## 核心算法

### 成长公式

所有属性成长和技能倍率使用统一的基础公式：

```
result = round(base + floor((growth * (lv - 1) + offset) / divisor), 1)
```

| 参数 | 含义 | 典型范围 |
|------|------|---------|
| `base` | 初始值（等级 1） | 0–1000 |
| `growth` | 成长系数 | 0–500 |
| `divisor` | 除数（控制曲线陡峭度） | 1–1000 |
| `offset` | 偏移量（微调中间等级） | -500–500 |
| `lv` | 等级（1–90） | 1–90 |

技能倍率类似，但等级范围为 1–12（含特殊值 `special` 数组记录 10–12 级的非标数据）。

### 反向推导（Inverse）

给定已知的等级数据（90 级属性或 12 级技能倍率），自动反推 `(base, growth, divisor, offset)` 四参数：

| 函数 | 用途 |
|------|------|
| `fit_attribute_formula` | 90 级属性数据 → 四参数 |
| `fit_skill_formula` | 12 级技能倍率 → 四参数（含特殊值） |
| `fit_skill_formula_no_special` | 9 级技能数据 → 四参数（无特殊值） |

框架层的通用逆推引擎（`FormulaFitter` SPI、`InverseEngine`、`GameInverseAdapter`）见 [`ARCHITECTURE.md`](../ARCHITECTURE.md#关键抽象)。

### 15 乘区伤害模型

单段伤害计算串联 15 个乘区（`multiplicative_zones/`）：

| 乘区 | 模块 | 说明 |
|------|------|------|
| 基础区 | `base_zone.py` | 基础攻击力 |
| 属性区 | `attribute_zone.py` | 力量/敏捷/智识/意志 |
| 技能加成区 | `ability_bonus_zone.py` | 技能倍率 |
| 防御区 | `defense_zone.py` | 目标防御减伤 |
| 最终攻击区 | `final_attack_zone.py` | 最终攻击力加成 |

> DAG 适配器已拆为独立包 `games/endfield/calc/dag_adapter/`，生产入口见 `zone_snapshot/`。详见 [ADR-0020](adr/0020-multiplicative-zones-decouple.md)。

## 全量搜索流水线

搜索架构分为四层：

```
GUI → 搜索任务准备 → 搜索执行（并行/续跑）→ 任务评估 → 结果收集
```

### 搜索流程

1. **候选过滤** — 按武器名、装备名过滤，移除无益项
2. **优先级排序** — 按主/副能力、技能类型排序（不减组合数）
3. **固定配装** — 支持 0–4 件固定配装组合
4. **并行执行** — 有界并行流式提交，支持断点续跑
5. **任务评估** — 聚合修饰器 → 计算最终攻击 → 15 乘区单段伤害 →（多技能加权）
6. **Top-N 收集** — `TopNTracker` 维护最优结果集

### 续跑机制

- `run_signature`：基于配置+数据版本+代码版本生成唯一标识
- SQLite 持久化：`search_output/search_runs.db`
- 相同 `run_signature` + 未完成数据库 → 自动续跑

### 并行策略

| 环境 | 策略 |
|------|------|
| PyInstaller exe | QThread + 单 worker 内联 batch（Rust FFI） |
| 开发模式 | 多进程（可选 `parallel_backend=process`） |

## 数据格式规范

### 属性数据

90 个数值（等级 1–90）：

```json
{
  "力量": {"base": 10, "growth": 5, "divisor": 10, "offset": 0},
  "基础攻击力": {"base": 100, "growth": 50, "divisor": 10, "offset": 0}
}
```

### 技能倍率

12 个数值（等级 1–12），含特殊值：

```json
{
  "战技倍率": [
    {"base": 100, "growth": 50, "divisor": 10, "offset": 0, "special": [1050, 1100, 1200]}
  ]
}
```
