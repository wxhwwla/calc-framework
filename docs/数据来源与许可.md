## 十三、捐赠与创作者支持

### 13.1 捐赠的法律性质

本项目在 GUI 中提供「自愿捐赠」入口。捐赠**不是购买软件的对价**，**不触发** LICENSE 的商业许可义务（见 LICENSE §4 及 §5.3）。

**捐赠不授予：**
- 本仓库游戏数据的商业使用授权（见 DATA_LICENSE）；
- 替代 AGPL-3.0 开源义务的任何权利；
- 与游戏权利方的合作或背书关系。

### 13.2 捐赠图片资源

项目默认捐赠二维码存放在 [`resources/donation/donation_qr.png`](../resources/donation/donation_qr.png)（用户自行放置）。所有 GUI 的捐赠弹窗（`utils/donation.py`）和布局中的捐赠 widget 均默认读取此路径。打包 exe 时通过 `--add-data` 将该目录包含在发布包中。

### 13.3 嵌入 .calcpack 的捐赠 widget

配置包设计器（`tools/designer/`）允许在布局中嵌入捐赠 widget（`widget_type: "donation"`），含自定义文字和图片。导出 `.calcpack` 时：

1. **图片自动打包**：如果捐赠 widget 配置了本地图片，导出器（`tools/designer/exporter.py`）会自动收集图片文件，写入 `.calcpack` 的 `assets/` 目录
2. **路径自动重写**：layout.json 中的 `image_path` 导出时被重写为 `assets/<文件名>`，加载时自动解压到临时目录并恢复绝对路径
3. **未配图则回退**：如果 widget 未指定图片，默认显示 `resources/donation/donation_qr.png`（即项目默认捐赠二维码）

该 widget **随 .calcpack 配置包传播**：

- 创建者对其填入的捐赠内容和图片承担全部责任；
- 版权人（wxhwwla）不对用户创建的 .calcpack 中的捐赠内容作认可或担保；
- 接收方点击捐赠按钮是向创建者个人支付，与版权人无关。

### 13.4 税务提示

接受捐赠的开发者应自行了解并遵守所在司法辖区的税务申报义务。本文件不构成税务建议。

### 14.4 matplotlib

伤害仪表盘功能依赖 matplotlib（BSD-compatible 许可）。打包 exe 时 matplotlib 随附的字体和示例数据文件一并纳入，其许可文件保留在 matplotlib 包内。

### 14.5 Web 后端（fastapi / pydantic / uvicorn）

## 十五、发布包结构（exe 与数据分文件）

本仓库 `main_build.py` 产出 **三个独立发布文件夹**（`dist/` 下），而非单文件 exe 内嵌 JSON：

| 应用 | 数据 | 许可 |
|------|------|------|
| `终末地伤害计算器.exe` + JSON | `adapters/endfield/data/` | DATA_LICENSE |
| `数据设计器.exe` + JSON | 同上 | DATA_LICENSE |
| `配置包设计器.exe`（**不含 JSON**） | 不依赖本仓库数据 | 纯 LICENSE |

| 内容 | 许可 | 说明 |
|------|------|------|
| `*.exe` | LICENSE | 软件本体 |
| `adapters/endfield/data/*.json` | DATA_LICENSE | 含 `characters.json`、`weapons.json`、`equipments.json` |
| `DATA_LICENSE`、`LICENSE`、`NOTICES.md` | — | 合规声明 |
| `发布说明.txt` | — | 分发须知 |
| `search_output/`（运行后生成） | — | 用户本机搜索产出，**非**仓库随包数据；可删除 |

**物理分离**便于非商业分发时署名、更新数据；**商用仍须自备数据**（见第 §三节）。
