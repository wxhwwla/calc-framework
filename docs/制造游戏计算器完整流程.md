## 1. 总览：完整流程步骤

### 1.1 三层架构

```
第一层：乘区层（计算引擎）
  功能：定义所有伤害计算公式
  工具：DAG 图编辑器
  产出：xxx.dag.json（DAG 公式图文件）

第二层：布局层（UI 设计器）
  功能：将计算变量映射到用户界面控件
  工具：配置包设计器
  产出：layout.json（UI 布局文件）

第三层：展示层（用户框架）
  功能：加载数据 + 公式 + 布局，提供最终用户界面
  工具：CalcPackViewer / 游戏专用 GUI
  产出：.calcpack（打包后的适配包）
```

### 1.2 流程图

```
  开始
   │
   ├─── ① 数据准备 ─────────────────────────────┐
   │    ├─ 方法A：BWIKI 爬虫 → parsed/           │
   │    ├─ 方法B：手动录入（数据设计器）→ JSON    │
   │    └─ 方法C：OCR 截图识别 → 一键填入         │
   │    → 产出：characters.json / weapons.json    │
   │       equipments.json / enemies.json          │
   │                                              │
   ├─── ② 设计计算逻辑 ──────────────────────────┤
   │    └─ DAG 图编辑器                           │
   │    → 产出：xxx_full.dag.json（入口 DAG）     │
   │       dag/subgraphs/*.dag.json（子图，可选）  │
   │                                              │
   ├─── ③ 声明属性 Schema ───────────────────────┤
   │    ├─ attr_schema.json                       │
   │    └─ meta.json（适配器元数据）              │
   │                                              │
   ├─── ④ 设计 UI 布局 ──────────────────────────┤
   │    ├─ 配置包设计器（布局编辑）               │
   │    └─ 产出：layout.json                     │

   │                                              │
   ├─── ⑥ 打包分发 ──────────────────────────────┤
   │    ├─ 配置包设计器 → 导出 .calcpack          │

        ├─ Web 版：浏览器访问 /compute
        └─ 启动器：从 Calc Hub 下载适配包
```

## 2. 数据结构与文件格式

### 2.1 meta.json — 适配器元数据

**存放位置**：`framework/adapters/{游戏名}/meta.json`

**格式**：

```json
{
  "schema_version": "dag-v1",
  "name": "适配器显示名称",
  "game": "所属游戏名称",
  "version": "1.0.0",
  "description": "适配器功能描述",
  "author": "作者名（可选）",
  "entry_dag": "入口DAG文件名.dag.json",
  "attr_schema": "attr_schema.json（可选）",
  "functions": {
    "自定义函数名": "functions.py"
  },
  "plugins": ["依赖的插件名（可选）"],
  "tags": ["rpg", "action（可选）"]
}
```

**必填字段**：`name`、`game`、`entry_dag`、`description`

**字段规则**：
- `entry_dag`：相对于适配器目录的路径，指向主 DAG 文件
- `functions`：对象格式，key 为函数名，value 为路径
- `plugins`：数组，插件名与 `calc_framework.plugin.builtin` 中的注册名一致

### 2.2 .dag.json — DAG 公式配置文件

**格式版本**：`dag-v1`

**存放位置**：`framework/adapters/{游戏名}/`（主文件）或 `.../dag/`（子图）

**顶层结构**：

```json
{
  "schema_version": "dag-v1",
  "name": "DAG图名称",
  "description": "功能描述",
  "variables": {
    "source.属性名": {
      "type": "float|int|bool|str|percent",
      "source": "character|weapon|equipment|enemy|computed",
      "description": "说明",
      "default": 0.0
    }
  },
  "nodes": {
    "节点ID": {
      "type": "var|const|binary|unary|call|expr|condition|user_input",
      "label": "显示标签",
      "op": "运算类型",
      "value": 100.0,
      "path": "source.属性名",
      "lhs": "左操作数节点ID",
      "rhs": "右操作数节点ID",
      "subgraph": "子图ID",
      "bindings": { "参数名": "节点ID" },
      "default": 0.0, "min": 0.0, "max": 100.0, "step": 1.0
    }
  },
  "subgraphs": {
    "子图ID": {
      "description": "子图说明",
      "parameters": { "参数名": { "type": "float", "default": 0.0 } },
      "nodes": { "..." },
      "outputs": { "输出名": { "node": "节点ID" } }
    }
  },
  "outputs": {
    "输出名": {
      "node": "节点ID|子图ID.输出节点",
      "label": "显示标签",
      "format": "",
      "is_primary": true
    }
  }
}
```

**9 种节点类型**：

| type | 必填字段 | 功能 | 颜色 |
|------|----------|------|------|
| `const` | `value` | 固定数值输出 | 青 |
| `var` | `path` | 从 DataContext 读取变量 | 蓝 |
| `user_input` | `default`, `min`, `max`, `step` | 运行时用户输入 | 绿 |
| `unary` | `op`, `input` | 一元运算（neg/floor/ceil/abs/sqrt/ln/log10/sin/cos/tan） | 灰 |
| `binary` | `op`, `lhs`, `rhs` | 二元运算（+/-/*/^/mod/min/max） | 红棕 |
| `condition` | `cond`, `true_val`, `false_val` | 条件选择（0=假，非0=真） | 橙 |
| `output` | 无额外字段 | 标记输出结果 | 橙 |
| `call` | `subgraph`, `bindings` | 调用子图 | 紫 |
| `expr` | `expr`, `inputs` | 表达式字符串求值 | 粉 |

**DataContext 结构**（引擎运行时传入的数据来源）：

```
DataContext {
  character: { "基础攻击": 100, "防御": 50, ... },
  weapon:    { "攻击力+": 30, ... },
  equipment: { "暴击率": 0.15, ... },
  enemy:     { "防御": 200, "法术抗性": 50, ... },
  computed:  { "技能倍率": 1.0, "攻击力百分比加成": 0.0, ... }
}
```

### 2.3 attr_schema.json — 属性声明 Schema

**存放位置**：`framework/adapters/{游戏名}/attr_schema.json`

**格式**：

```json
{
  "attributes": [
    {
      "name": "攻击力",
      "type": "float",
      "source": "character",
      "default": 0.0,
      "description": "角色基础攻击力"
    }
  ]
}
```

**source 可选值**：`character` / `weapon` / `equipment` / `enemy` / `computed`
**type 可选值**：`float` / `int` / `bool` / `str` / `percent`

### 2.4 layout.json — UI 布局定义

**格式版本**：`ui-v1`

**存放位置**：`framework/adapters/{游戏名}/ui/layout.json`

**格式**：

```json
{
  "schema_version": "ui-v1",
  "name": "计算表名称",
  "description": "描述",
  "sections": [
    {
      "id": "section_id",
      "type": "inputs|outputs|widget",
      "title": "区块标题",
      "columns": 2,
      "variables": ["user_input.变量名"],
      "outputs": ["DAG输出名"],
      "widget_type": "donation",
      "widget_config": { "image_path": "assets/..." }
    }
  ]
}
```

**三种 Section 类型**：

| type | 必需 | 渲染效果 |
|------|------|----------|
| `inputs` | `variables` | 自动为每个 user_input 变量生成控件（滑块/输入框/开关等） |
| `outputs` | `outputs` | 显示 DAG 求值结果 |
| `widget` | `widget_type` | 渲染特殊组件（当前仅支持 `donation` 捐赠展示） |

### 2.5 .calcpack — 适配包打包格式

**格式**：ZIP 压缩包，扩展名为 `.calcpack`

**内部结构**：

```
*.calcpack
├── meta.json          （必填）适配器元数据
├── *.dag.json         （必填）DAG 公式文件
├── attr_schema.json   （可选）属性 Schema
├── layout.json        （可选）UI 布局
├── ui/theme.json      （可选）主题配置
├── assets/            （可选）资源文件（捐赠图片等）
└── functions.py       （可选）自定义 Python 函数
```

**生成方式**：使用配置包设计器（GUI ③）的「主题与导出」页签 → 点击「导出 .calcpack」

### 2.6 .calcplugin — 插件打包格式

**格式**：ZIP 压缩包，扩展名为 `.calcplugin`

**内部结构**：

```
*.calcplugin
├── plugin.json        （必填）插件元数据
├── variables.json     （可选）变量声明
├── templates.json     （可选）DAG 模板定义
├── functions/         （可选）Python 函数模块
│   ├── __init__.py
│   └── *.py
└── README.md          （可选）使用说明
```

**plugin.json 格式**：

```json
{
  "name": "插件名称",
  "version": "1.0.0",
  "description": "插件功能描述",
  "author": "作者"
}
```

**构建命令**：
```bash
python tools/plugin_pack.py build path/to/plugin_dir -o output.calcplugin
python tools/plugin_pack.py install path/to/plugin.calcplugin
```

### 2.7 数据文件格式

**字符数据**（characters.json）：

```json
[
  {
    "名称": "角色名",
    "类型": "职业/分类",
    "星级": 5,
    "武器": "武器类型",
    "等级": [1, 2, 3, ..., 90],
    "基础攻击力": [29, 31, 34, ...],
    "基础生命值": [800, 810, ...],
    "基础防御力": [...],
    "天赋": [ ... ]
  }
]
```

**关键约定**：
- 数组中每个对象的字段名如果是数组（且所有元素为数值），则按 `level-1` 索引取值
- 忽略的元数据 key：`名称`, `技能`, `类型`, `星级`, `武器`, `等级`, `潜能`, `信赖`

### 3.1 启动与窗口布局

**启动方式**：
```bash
python -m calc_framework.graph_editor
```

**窗口结构**：三栏布局，由 QSplitter 分割

```

│          │                            │                  │
│ 节点面板  │       画布 (Canvas)        │   属性面板        │
│          │                            │                  │
│ ┌──────┐ │   ┌──────┐                 │  ┌────────────┐ │

│ │基础   │ │   │  5.0  │    │binary│   │  │ 类型: const │ │
```

工具栏位于菜单栏下方，共 9 个按钮：

```
[新建] [打开] [保存] [导入包] [删除] [适配] [重置] [运算] [清除]
```

| 按钮 | 快捷键 | 功能 |
|------|--------|------|
| 新建 | Ctrl+N | 同文件→新建 |
| 打开 | Ctrl+O | 打开 .json 文件 |
| 保存 | Ctrl+S | 保存当前图 |

### 3.4 节点面板详解（左栏）

节点面板按分类 Tab 组织，每个 Tab 包含可拖拽的节点类型项。

#### 输入 Tab

| 节点类型 | 拖拽结果 | 用途 |
|----------|----------|------|
| 变量引用 | 创建一个 `var` 节点 | 从外部数据源读取属性值 |
| 用户输入 | 创建一个 `user_input` 节点 | 运行时由用户提供数值 |

#### 基础 Tab

| 节点类型 | 拖拽结果 | 用途 |
|----------|----------|------|
| 常量 | 创建一个 `const` 节点 | 定义固定数值 |
| 一元运算 | 创建一个 `unary` 节点 | 对单个输入执行数学运算（取反/绝对值/三角函数等） |
| 二元运算 | 创建一个 `binary` 节点 | 对两个输入执行数学运算（加减乘除等） |
| 条件判断 | 创建一个 `condition` 节点 | 根据条件选择输出值 |

#### 输出 Tab

| 节点类型 | 拖拽结果 | 用途 |
|----------|----------|------|
| 输出标记 | 创建一个 `output` 节点 | 标记计算结果为重要输出，编译时自动收集 |

#### 包 Tab

| 节点类型 | 拖拽结果 | 用途 |
|----------|----------|------|
| 已导入的复合节点 | 创建对应的复合节点实例 | 将子图封装为可复用的计算块 |
| [导入包] 按钮 | - | 打开文件对话框，选择 .json 或 .zip 导入复合节点 |

### 3.5 画布操作指南（中栏）

#### 节点操作

| 操作 | 方法 | 备注 |
|------|------|------|

双击复合节点打开子图编辑器对话框：

```

│  │  user_input  │                             │

│  └─────────────┘    │binary│──→ ┌────────┐  │
│  ┌─────────────┐    │  +   │    │ output │  │

│  │  (输入参数)   │               └────────┘  │
```

### 3.8 编译与求值

点击工具栏「运算」按钮后：

1. **收集**：`collect_document()` 从画布上收集所有节点和连线
2. **编译**：`compile_graph()` 将编辑器格式转换为 DAG 引擎格式
3. **求值**：`evaluate_graph()` 执行 DAG 并计算所有节点
4. **输出**：弹出对话框显示所有 output 节点的计算结果

### 15.3 PyInstaller 打包（单 exe）

**适用场景**：为终端用户提供无需 Python 环境的独立 exe

```bash
# 使用打包脚本
```

**生成的 exe 路径**：`dist/` 目录下

## Appendix A：常见问题

**Q: 如何创建一个新的游戏适配器？**
A: 在 `framework/adapters/` 下创建游戏同名目录，至少包含 `meta.json`、`*.dag.json`、`attr_schema.json`。参考已有适配器（如 `endfield/` 或 `arknights/`）的结构。

**Q: DAG 图编辑器的 .json 文件和适配器的 .dag.json 文件是什么关系？**
A: DAG 图编辑器的 .json 是编辑器内部格式（含位置/布局信息），适配器的 .dag.json 是编译后的引擎格式。编辑器可以「保存」为引擎格式。

**Q: 如何更新游戏数据（如新角色属性）？**
A: 方法1：重新运行 BWIKI 爬虫。方法2：在数据设计器中手动编辑。方法3：在 JSON 文件中直接修改。

**Q: CalcPackViewer 和游戏专用 GUI 有什么区别？**
A: CalcPackViewer 是通用查看器，自动适配任何 .calcpack 的内容。游戏专用 GUI（如终末地计算器、明日方舟计算器）针对特定游戏做了定制化界面（如角色选择联动、全量搜索、OCR 识装等高级功能）。

**Q: Web 版和桌面版的功能完全一致吗？**
A: 核心计算功能一致。桌面版有更强大的搜索功能（多线程并行搜索）、文件拖放操作。Web 版有更方便的分享功能、无需安装、跨平台。

**Q: 如何添加新的自定义函数到 DAG 中使用？**
A: 在适配器目录下创建 `functions.py`，定义 Python 函数，在 `meta.json` 的 `functions` 字段中注册，即可在 DAG 的 `expr` 类型节点中使用。
