## 1. 总结与使用说明

### 1.1 总体结论

项目的通用计算框架、终末地计算核心、配装搜索、Web 后端、前端生产构建、CalcPack 和已有 PyInstaller 程序均有可运行证据。

当前不宜直接宣称“完整可发布”，主要阻断项是：

1. 桌面端确认计算后，15 乘区表因错误路径而加载失败。
2. 搜索预估因控件属性名不一致而持续报错。
3. `calc-framework-endfield` wheel 缺少计算、GUI 和数据，pip 安装形态不可用。
4. 安装包无法完成验收；发布链允许安装包构建失败或缺失后继续发布。
5. 明日方舟和 Framework 存在真实测试失败，部分自动测试还有假阳性或宽松退出。

### 1.2 问题状态定义

- **已复现**：本次在本机执行命令或实际操作后直接观察到。
- **静态确认**：代码路径、配置或发布文件可直接证明，但不声称已完成运行时复现。
- **文档失配**：文档声明与当前代码、文件或实测结果不一致。
- **待复核**：目前证据不足，必须补测试后才能定性，不应当作已确认 Bug 修复。

### 1.3 优先级定义

- **P0**：主流程阻断、安装后不可用，应最先修。
- **P1**：真实测试失败、发布可靠性、明显功能错误或测试假阳性。
- **P2**：文档、可维护性、测试覆盖和兼容性债。
- **P3**：性能、警告和后续验收项，不阻塞前四项优先修复。

## 6. P3：警告与后续验收项

### P3-01 大规模搜索性能目标尚未验证

- **状态**：**已达成（2026-11-03）**。首轮基准 `rust_full` 28.36s；最终攻击力按装备属性签名记忆化后降至 **9.75s**，满足 `<10s`。

- **固定基线**：数据版本 `1.1.0`；当前武器 + 全部装备（剪枝后 24×23×42²）= **973,728** 组合；伊冯 / 佩科5 / 战技，角色与武器 90 级、信赖 4、敌方防御 100。
- **实测（Windows 11 / Python 3.13 / 24 逻辑核）**：

| 模式 | 首轮耗时 | 优化后耗时 | 组合/秒 | 峰值 RSS | `<10s` |
|------|---------:|-----------:|--------:|---------:|:------:|
| `rust_full`（默认） | 28.36s | **9.75s** | 99,878 | 634 MB | ✅ |
| `rust_soa`（`CALC_RUST_FULL_BATCH=0`） | 45.71s | 48.11s | 20,238 | 1005 MB | ❌ |
| `python`（`RUST_SEARCH_FALLBACK=1`） | 78.65s | 77.07s | 12,634 | 620 MB | ❌ |

- **TopN 一致性**：三模式 TopN（N=10）完全一致 ✅。
- **取消/续跑**：SoA + SQLite 路径在 `processed=100,000` 取消成功；续跑跳过 100,000 条已预处理记录，最终 973,728/973,728，耗时 58.98s ✅。

- **验收中发现并修复**：Rust 全批量把 `DamageEffect` 压平为 `(type, value)`，丢失 `damage_types` / `skill_types` / `require_unbalanced`，导致终结技等作用域外效果被计入战技搜索（单配装 11096.62 vs 10007.43）。已在 `full_batch_eval.py` 增加作用域过滤，并修正 `rust_bridge._build_scope_filter` 仅按效果类型缓存的问题；新增 2 个回归测试。详见 [`错误集.md`](错误集.md) 2026-11-03 条目。
