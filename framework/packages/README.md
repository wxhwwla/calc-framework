# 子图包目录

此目录用于存放可复用的子图和子图包。

## 自动发现

图编辑器启动时会自动扫描此目录下的所有 `.json` 和 `.zip` 文件，并将其注册为复合节点。

## 文件格式

### 单个子图 (.json)
```json
{
  "schema_version": "calc-graph-v1",
  "name": "子图名称",
  "nodes": [...],
  "edges": [...]
}
```

### 子图包 (.zip)
```
子图包.zip
├── 子图1.json
├── 子图2.json
└── 子图3.json
```

## 使用方法

1. 将 `.json` 或 `.zip` 文件放入此目录
2. 启动图编辑器
3. 在"包"选项卡中可以看到自动加载的子图
4. 拖拽到画布即可使用

## 示例

```
framework/packages/
├── README.md           ← 本文件
├── 攻击力计算.json      ← 单个子图
├── 战斗计算包.zip       ← 子图包（包含多个子图）
└── 通用公式/           ← 子目录（暂不支持自动扫描）
    └── 暴击计算.json
```

## 注意事项

- 目前只支持扫描根目录下的文件，不支持递归扫描子目录
- 文件名会作为子图的显示名称
- ZIP 包中的所有 `.json` 文件都会被加载
